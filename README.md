# 游戏

个人游戏与学习软件合集：一个 CS2 / 无畏契约练枪平台，一套大学英语读写 3 与四六级的学习游戏。

## 项目

| 目录 | 内容 | 技术 |
|---|---|---|
| [电脑游戏/](电脑游戏) | **AimForge**：单机 CS2 / 无畏契约练枪平台（非官方）。甩枪、跟枪、压枪、预瞄、反应五种训练模式，目标 700+ FPS、零 GC 热路径、Raw Input 低延迟 | .NET 9、OpenGL |
| [手机游戏/word-quest/](手机游戏/word-quest) | **Word Quest 学习内容库**：四级约 4543 词、六级约 3991 词、读写教程 3（6 个单元）三套课程数据，为《四六级 RPG》手机游戏提供词汇与关卡结构 | 数据工程 |
| [手机游戏/word-quest-game/](手机游戏/word-quest-game) | **词场冒险**：大学英语读写教程 3 的三维学习游戏，每个单元一个主题空间，边探索边收集词汇，再回到学习圣所完成读写任务 | 三维网页 |
| [手机游戏/word-quest-ue/](手机游戏/word-quest-ue) | **Word Quest UE5**：读写教程 3 学习软件的 Unreal Engine 5.8 客户端，目前是工程骨架，四六级暂不接入 | Unreal Engine 5.8 |
| [微信游戏/](微信游戏) | 预留目录，暂无内容 | - |

各项目的运行方式见各自目录下的 README。
