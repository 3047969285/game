# 词场冒险 · 大学英语读写教程 3 三维学习游戏

打开即玩：在三维单元世界里探索路线、收集词汇，再回到学习圣所完成读写任务。

## 功能

- 读写教程 3 六个单元，每单元 20–30 个核心词汇（以当前单元数据为准）
- 每个单元独立的三维主题空间：数字港湾、知识市集、记忆森林、思想神殿、轨道校园等
- 中央学习圣所、四条收集路线、四个学习站点和可视化进度
- 词汇光球探索收集：释义、词性、例句和浏览器朗读
- 读写教程 3 学习链：Section A/B/C、词汇 4 关、阅读、听力、语境填空、翻译、写作、语法工坊、记忆远征
- 六个单元各自拥有原创世界叙事：导师、任务、转折、结局、四个空间地标和单元记忆锚点
- 世界观赏模式：可以隐藏角色、锁住行走，只拖动镜头查看完整三维场景
- 本地自定义音乐：选择设备上的音频文件后播放、暂停、调节音量和循环；文件不会上传
- 单元完成奖励：徽章与 XP 写入本地存档，重复完成不会重复领取
- 语法工坊：每单元两组语法讲解，配例句、易错点和原创应用题
- 记忆远征：将主动回忆、间隔回访、故事链、空间记忆、交错练习、生成效应和迁移表达转化为可执行的游戏动作
- 四级 / 六级 / 读写教程 3 数据均可在同一入口切换

## 内容来源边界

项目中的世界叙事、语法讲解、应用题和记忆训练为原创游戏内容；现有读写3数据包按单元结构提供词汇与学习模块。教材的完整文章、完整练习题和答案属于受版权保护的内容，不能从非授权网站整本抓取后公开打包。

如果后续接入你合法拥有的教材文件或出版社授权资源，应放在受控的授权内容层，并沿用现有 `Rw3UnitContent` 数据接口；不要把未授权全文提交到公开仓库。外研社的官方教材支持页和教师用书入口可作为授权资源的核验起点。

## QQ / 微信登录配置

前端只负责跳转到后端 OAuth 发起地址，不保存也不接收 QQ 或微信的 `AppSecret`。部署时可以通过环境变量提供：

```text
VITE_QQ_AUTH_URL=https://your-server.example.com/oauth/qq/start
VITE_WECHAT_AUTH_URL=https://your-server.example.com/oauth/wechat/start
```

后端需要完成开放平台授权、`code` 换取用户身份、回调校验、会话建立和账号绑定；没有真实的后端地址和开放平台资质时，登录按钮会保持不可用，不会伪造登录成功。

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5173

如果旁边没有原始 `word-quest` 数据仓库，打包脚本会保留仓库内已经提交的 `public/data`，项目仍然可以直接启动。
