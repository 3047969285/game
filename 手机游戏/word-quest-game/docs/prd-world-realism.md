# PRD：三维世界写实化重建

## 背景

当前世界的渲染管线已经完整（PMREM 天空反射、GTAO 环境光遮蔽、泛光、调色、地形法线贴图、成片植被），
但画面仍偏"卡通 / 玩具感"。主要原因不在管线，而在资产本身：

| 现状 | 问题 |
|------|------|
| 地表是均匀的饱和绿色，草叶颜色单一 | 缺少泥土、枯草、碎石、坡面岩石的过渡，像一张绿毯 |
| 树冠是顶点色团块 + 256px 叶片贴图 | 近看是色块，叶片没有透光、没有风动 |
| 松树是 7 层圆锥叠成 | 轮廓像圣诞树玩具，不像真实针叶树 |
| 岩石是噪声变形的二十面体，纯顶点色 | 没有表面纹理、苔藓、风化 |
| 道路是一块块方盒子石板（约 220 个独立网格） | 形状规整、颜色一致，接缝不自然 |
| 水面是半透明平面 | 没有波纹法线、菲涅尔、深浅色、岸边泡沫 |
| 建筑和地标是单色 PBR 材质 | 墙面、木材、金属缺少纹理和磨损 |
| 整体饱和度、对比度偏高 | 色调偏动画，缺少大气透视 |

## 目标

让玩家第一眼感觉是"写实的自然场景"，而不是卡通地图；同时保持现有玩法、布局和单元主题不变。

## 范围与阶段

每个阶段都单独可交付、单独验收，按画面影响从大到小排序。

| 阶段 | 内容 | 关键产出 |
|------|------|----------|
| 1 天空、大气与调色 | 物理天空（瑞利 / 米氏散射）、按距离与高度变化的大气透视雾、更自然的色调映射与调色、更柔和的阴影 | 远景自然发蓝发灰，近景色彩真实，不再过饱和 |
| 2 地表与草地 | 地形按坡度 / 高度 / 噪声混合草地、枯草、泥土、碎石、岩面；高分辨率程序纹理 + 法线；草叶色彩随机、根部更暗、风吹摆动；草地与地面颜色过渡 | 地面有层次，草地像真实草地 |
| 3 植被 | 高分辨率叶片贴图（叶脉、色差、透光）、树皮法线纹理、针叶树改为枝条 + 针叶卡片结构、树和灌木受风摆动、叶片背光透射 | 树木近看也写实 |
| 4 岩石与道路 | 岩石加表面纹理、苔藓（朝上一面）、风化色差；道路改为不规则石板 + 泥土路缘，合并为少量网格 | 岩石和道路不再像积木 |
| 5 水面 | 双层滚动法线波纹、菲涅尔反射、深浅水色、岸边泡沫与湿润带 | 湖面像真实水体 |
| 6 建筑与地标 | 墙面（灰泥 / 砖 / 石）、木材、金属的程序纹理与法线，边角磨损与污渍 | 建筑材质可信 |

## 非目标

- 不改玩法、地图布局、单元内容和 UI。
- 不引入外部图片或模型资源：所有纹理在运行时程序化生成（保持离线可用、无版权问题）。
- 不改主角和 NPC 的造型。

## 约束

- 低画质档（手机）必须仍然流畅：每个阶段新增的开销在 low 档要能关掉或降级。
- 每帧绘制调用不能因写实化而增加；阶段 4 合并道路后应明显下降。
- 程序纹理在启动时生成，总耗时增加不超过 300ms（高画质档，桌面浏览器）。
- 所有新增纹理和材质在切换单元 / 销毁世界时正确释放。

## 验收方式

每个阶段都在同一组固定视角下截图，和改动前对比：

1. **出生点**：页面加载后的默认视角。
2. **全景**：观赏模式，镜头上抬并拉远。
3. **侧向**：全景视角向左旋转。
4. **单元世界**：进入 Unit 1 学习场景后的默认视角。

每个阶段的验收标准：

- A1 固定视角截图对比，写实度明显提升，没有新的穿帮（悬空、闪烁、接缝、穿模）。
- A2 浏览器控制台没有报错。
- A3 每帧绘制调用不增加（阶段 4 之后要下降）；高画质下帧率不低于改动前的 85%。
- A4 新增的纯逻辑模块（纹理生成参数、布局、混合权重）有 vitest 单元测试，`npm test` 和 `tsc` 全部通过。
- A5 低画质档能正常运行，新开销已降级。

## 基准数据（改动前，主世界出生点，med 画质）

- 主画面每帧绘制调用 520，阴影 67；每帧约 109 万三角形（主画面）。
- 切换单元 3 次，几何体数量稳定在 344，无泄漏。
