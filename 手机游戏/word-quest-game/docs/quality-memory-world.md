# 记忆重现与三维空间细化

## 产品需求说明书

本轮优先画面质量：改善回忆教室近景材质、显形光效与空间层次。范围为通用教室和《周四的沉默》社团教室，以及所有回忆共享的显形器；不将局部舞台细化描述为整个探索地图重做。

- 显形采用较窄的青蓝外缘、暖金细芯；降低边缘能量和预显形点阵密度，避免厚白光吞掉材质。汇聚粒子加入幅度受限的螺旋偏移，首尾偏移为零，最终落回表面。
- 窗边浮尘随地板、窗口重现进度渐入，缓慢漂移且近相机淡出，不作为新光源或声音。高、中、低分别 240 / 160 / 80 点，仅一批绘制，不逐帧分配顶点缓冲。
- 教室桌椅采用细密、低对比的室内木纹；地板板缝使用真实米制间距与错缝，而家具不再带建筑木板的大缝。墙面改为轻微灰泥色差，去掉不协调的大面积破损。
- 桌面增加展开笔记本的双页、页边、缝线、短书写痕迹、书签与带金属夹的笔；通用教室增加桌脚连接件。细节合并到原部件，沿用显形、阴影和生命周期。
- 社团教室窗光束的四周柔化，避免透明硬片感。保留现有雨夜视觉与音乐/旁白，不引入合成环境噪声。
- 尊重减少动态效果：浮尘不漂移，原显形器仍直接展示静态表面；保留主模型、材质与空间结构。

## 接口文档

新增内部 `MemoryAir(bounds, quality, reduced?)`：object 为单个 Points；`update(time,visibility,heightPx,fov)` 更新少量 uniforms；`dispose()` 幂等释放几何、材质并移除对象。MemoryStage 仅在 emptyRoom / clubRoom 创建并释放，时间沿用舞台时钟，因此定格时不继续漂移。

`interiorKit(kit)` 返回局部材质替换的 SceneKit，不修改调用者的共享套件。`interiorWood` / `interiorPlaster` 的 onBeforeCompile 与 Materializer 原有显形补丁串联，完成后恢复原物体颜色，无新后期通道和灯光。

`studyNotebook(kit,frame)`、`floorJoints(kit,width,depth)` 写入现有合并构建器；部件命名、交互摆放位和剧情接口不变。

开发页 tools/memory-world-test.html 使用正式舞台、显形器和浮尘，可重播、暂停、切换空间/桌面机位及高低画质。它是无演员、无音频的空间预览，不能代替游戏剧情验证。

## 测试

新增浮尘分档数量、固定种子、空间边界、渐入、减少动态模式、缓冲复用和幂等释放回归；保留各舞台目标映射、几何与绘制预算、显形深度补丁和中断生命周期测试。浏览器检查高/低画质两间教室、重现中途与完成后的近景，检查真实游戏入口与 WebGL 错误。

不把浏览器模拟画质或绘制计数当作真机帧率测试。

最终验证：46 个 Vitest 文件、592 项用例通过，7 项 Python 数据测试通过；TypeScript 检查与 Vite 生产构建通过。浏览器已观察高画质社团教室的完整近景、重现中途与真实游戏互动状态，以及低画质通用教室完整空间；未捕获 WebGL/着色器错误。现有舞台网格预算继续通过，新增浮尘仅一个 Points 批次。开场、退出和配乐暂停状态保持正常。
