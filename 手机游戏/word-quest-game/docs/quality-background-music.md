# 场景背景音乐

## 产品需求说明书

用户要求制作高质量、好听、适合英语三维游戏的背景音乐。旧功能只有本地音频导入，不含实际配乐。本轮交付三首新编器乐作品，包含主题、和声、分段发展、自然停顿、轻微演奏时差、立体声和空间混响。

| 场景 | 曲名 | 音乐与编配 | 时长 |
| --- | --- | --- | --- |
| 主世界 / 单元探索 | 光下的远行 | D 大调钢琴主题、分解和弦、采样竖琴回应、温暖铺底 | 96 秒 |
| 开场 / 回忆 / 电影机位 | 把昨天轻轻拾起 | 较慢的钢琴旋律，低音区引子与回归乐句 | 90 秒 |
| 学习 / 纸上笔记 | 窗边的专注 | 稀疏钢琴、长和声、更多留白，降低注意力竞争 | 96 秒 |

首次手势后开启，自动模式随场景切换；支持固定曲目、暂停、音量、本地音频导入。音乐控制器在所有三个屏幕均可用。暂停意图、音量和固定曲目保存在浏览器中；离开页面可暂停，回来只恢复原本启用的音乐。英语朗读发声期间将音乐降至用户音量的 16%，结束、取消、错误或超时后恢复。原有雨声减轻，避免覆盖配乐与英语。

采样为 VCSL 真实录制的 Kawai 钢琴和音乐会竖琴，固定版本及 SHA-256 来源可追溯，采用 CC0 许可；旋律、和声、编配由本项目新编，不复制现成歌曲。音频本地提供，运行时不访问音乐服务。实际文件为 44.1 kHz 双声道 AAC；三首合计约 5.13 MB。制作过程保留动态余量，编码后已解码检查峰值与连续能量。

## 接口文档

- `MusicPlayer.setScene("explore" | "memory" | "study")`：只影响自动模式，使用双音轨 1.2 秒等功率淡入淡出；WebAudio Gain 曲线避免低频率音量跳变。
- `select("auto" | "explore" | "memory" | "study" | "custom")`：选曲，custom 需要先 `load(file)`。
- `unlock()`：在用户手势中解锁 AudioContext 和两个媒体元素，兼容需要逐元素手势的浏览器；被拦截时可手动播放重试。
- `toggle()`、`setVolume(0..1)`、`setLoop(boolean)`：控制用户意图；内置曲目始终循环，本地曲目可关闭循环。
- `subscribe(listener)`：界面订阅播放状态；`name/status/position/duration/selected/level/playing` 提供当前状态。切换到未播放曲目时显示其自己的起点与时长。
- `dispose()`：停止两轨、取消淡化任务、移除手势/页面监听、关闭上下文、释放本地 blob URL。异步 play 的迟到完成不能重新播放。
- `beginSpeech(): () => void`：分配语音焦点并返回幂等释放函数；`onSpeechActivity(listener)` 订阅是否有任何语音占用焦点。Narrator 仅在实际发声时开始，结束/取消时释放，计时降级不压低音乐。
- `MemoryStageOptions.onMusicScene`：可选回调，电影与第一人称回忆选择 memory，纸页学习选择 study；App 返回地图选择 explore。
- `mountMusicControls(root, player)`：全局单一控件，使用文本节点展示用户文件名，支持键盘选择和 Escape 收起；手机视口宽度约束在屏幕内。
- 成品在 `public/audio/`，制作脚本在 `scripts/music/compose.py`，采样清单在 `scripts/music/sample-sources.json`。重制需要 NumPy 与 macOS afconvert，游戏运行不需要这些工具。

## 测试

自动回归覆盖首次手势、两轨交叠和旧轨停止、连续快速切曲、暂停跨场景保留、语音重叠与取消后的音量恢复、存储恢复、无效音量、自动播放拒绝后重试、页面隐藏与恢复、本地音乐循环与 blob 回收、销毁后的异步回调。Narrator 新增实际发声/取消/迟到事件与音乐焦点的集成回归。

音频资产检查校验 AAC 容器、音轨、三首独立哈希、时长、立体声采样率、PCM 峰值/能量与循环首尾。编码成品另外经 afconvert 解码：峰值分别 0.7593 / 0.7590 / 0.7613，均未达到满幅；RMS 分别 0.0990 / 0.0793 / 0.0754，保留段落动态，未作强行响度压平。

浏览器检查：首次点击播放、曲目对应的 1:36 / 1:30 时长、实际播放进度、探索曲 96 秒后循环、手动暂停后切歌仍暂停、刷新保留设置；进入回忆自动选择回忆主题，控件在全屏回忆之上可操作。379×844 CSS 视口中面板宽 310px、x=57、y≈393、底部≈784，未超出屏幕；检查后已恢复默认视口。

最终整套测试、生产构建与提交结果由主执行者补录。未做真实 iOS/Android 设备听感和硬件音频测试；作曲审美可通过交付的原曲与 18 秒试听片段直接判断。
