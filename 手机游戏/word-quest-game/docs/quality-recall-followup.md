# 回溯画面与入场镜头补充修复

## 产品需求说明书

入场应贴近人眼高度、接近场景，天气等开场设定不能使机位初始化失效；首段运镜应连续接续。回忆画面的墙体、显形光、窗边浮尘应采用中性偏冷的科技感，并继续随单元色调变化。

## 接口文档

- `firstIntroShot(beats)`：跳过开场天气、等待、无镜头视角设定，读取首个叙事镜头。
- `closeIntroShot(shot,spawn,bounds)`：纯函数，起点与首段终点限制在出生地面上方 1.45–1.7 米、距离目标不超过 3.2 米，并约束在舞台相机边界内；没有叙事镜头时也提供明确的眼高机位。
- `MemoryStage`：初始化相机及 CinemaDirector 的同一姿态，首个剧情镜头使用同一近景替换，后续镜头保持原接口。
- `Materializer.setEdgeColor(r,g,b)`：共享舞台颜色对象，所有显形部件随当前单元色调更新，不逐帧创建颜色。
- `MemoryAir.setTint(r,g,b)`：更新浮尘颜色；墙面改为中性冷灰，减轻固定暖黄底色。

## 测试

新增天气/视角前置时的镜头解析、起终点高度与距离、原镜头不被改写、无镜头出生点回退测试。完整回归和 TypeScript 检查通过后提交。性能沿用已有自适应分辨率、骨骼距离分档及天气实例化；本轮没有把代码检查声称为实际帧率提升或真机测试。
