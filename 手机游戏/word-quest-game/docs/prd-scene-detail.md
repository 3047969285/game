# PRD：学习场景近景精细化

## 产品需求说明书

延续六个单元的三维学习场景，本轮细化共用的书本、笔记本电脑、长椅和花坛。保留关卡、学习入口、相机和交互位置，让近看时能识别真实结构，而不是增加散落物件的数量。

| 编号 | 需求与验收 |
| --- | --- |
| R1 | 翻开的书有弯曲纸页、中央装订沟、印刷行与书签；书堆能分辨封面、纸页和书脊。 |
| R2 | 笔记本有独立键帽、触控板、铰链、屏幕边框与简单的屏幕内容；屏幕内容贴合倾斜面，不悬浮或穿模。 |
| R3 | 长椅有镂空支撑、弯曲扶手、脚垫与金属固定件；座面与靠背位置不变。 |
| R4 | 花坛改为真实中空石圈和凹入的土面，消除原先石圈顶面与土面重叠；枝叶间有带花瓣的花朵。 |
| R5 | 默认高/中画质展示细节，低画质减少印刷、键帽、花瓣和叶片数量，保留主要轮廓。 |
| R6 | 小件继续按材质合并，不能每个键帽、螺丝或花瓣单独产生绘制调用。默认单道具几何上限：书堆 3000、翻开书 1600、电脑 2600、长椅 6500、花坛 7000 个三角形。 |
| R7 | 使用固定种子。相同参数的几何、布局和材质分组一致；不新增网络资产、字体或账号依赖。 |
| R8 | 叶片卡片不能采到图集中预留给实心树冠的白色色块，消除叶丛周围的悬空白点。实心树冠仍保持原有不透明采样。 |

## 接口文档

见 [api-scene-detail.md](api-scene-detail.md)。无新增 HTTP 接口，沿用内部场景构建接口。

## 测试与画面验收

- 几何测试检查纸页曲率、左右对称、法线与边界、花坛环形开口。
- 道具测试检查高低画质、固定种子、合并后网格数和三角形预算。
- `npm test` 与 `npm run build` 必须通过。
- 在场景预览器和真实游戏里检查书桌、户外与其他单元的场景，记录控制台错误、绘制调用与三角形数。比较同机位画面；场景三角形增幅以 10% 为目标上限，绘制调用增加不超过 8 次。该统计不等同于实机帧率保证。

## 本轮补充：共用房屋立面

本轮细化 `house()` 共用的小房屋门窗，不改房屋外轮廓、场景路由、交互、碰撞、门中心、门槛及入口坐标。实现范围覆盖实际调用共享 `house()` 的 unit01、unit02、unit03、unit06 场景；unit04、unit05 本轮没有房屋立面变化。书店展示窗和旅舍二层窗继续使用既有 `windowPane()` 默认样式，作为兼容验收对象。

| 编号 | 需求与验收 |
| --- | --- |
| R9 | 房屋正面必须由墙体分段形成真实门窗洞口；玻璃与暖光背板应位于洞口/墙体的前后层次中可见，不能被实心外墙遮住。 |
| R10 | 门框、门板、窗框、窗台、过梁和洞口侧边形成清楚层次；窄立面下，窗框与窗台/过梁外包边界均须与门框留至少 0.04m 净距，窗外饰边保留至少 0.05m 墙边距。 |
| R11 | 四周墙和分段前墙在近景观察无可见漏缝；房屋转向后门窗仍朝向立面外侧。书店橱窗陈列、旅舍二层窗和暖光保持可见。 |
| R12 | 房屋在 low 档继续使用真实洞口和主结构，减少窗棂与窗帘几何；单屋不超过 3500 个三角形、10 个合并网格，且 low 面数少于 high。 |
| R13 | 不改变门洞/台阶位置、场景入口、学习进度、碰撞或玩法状态。最终场景抽样以 resilience 单屋阵列增幅不超过 5% 三角形、绘制调用不增加为目标；此抽样预算不代表 FPS。 |
