# 世界画质提升与验收记录

## 产品需求说明书

人物与人物外观由 Claude 负责，本轮仅处理世界、场景材质与渲染。目标是向写实开放世界推进；现有程序建筑/植被与商业大作仍有明显资产差距，不将引擎功能清单等同于达到《极限竞速：地平线》成片质量。依次验收光照、地形、植被、表面、天气、性能；每项运行完整测试与 TypeScript，并保留同机位截图。

## 接口文档

### 1. 光照与大气

- `solarPosition(hour,latitude,dayOfYear)` 使用太阳时、纬度、日期计算 Y-up 太阳方向。默认北纬 31.2°、第 172 天、14 时，以真实太阳高度替代永不落山的正弦摆动；游戏时间一秒对应太阳时一秒。
- `makePhysicalSky` 使用项目自带 Three.js MIT Sky：Preetham 天空、波长相关瑞利项、前向米氏项、云覆盖。统一标定 HDR 能量，避免高能天空触发整屏泛光。主世界天空和全部回忆的 PMREM 环境反射共用物理天空；室内保留作者设定的太阳入射方向。
- `WorldCascades`：high 三段 2048、med 两段 1024、low 单原始阴影；实用分割、边界淡化、相机跟踪、自动投影更新。链式保留地形/植被原着色器，不改人物外观模块。
- HDR HalfFloat → 太阳方向/高度雾积分 → 深度重投影 TAA → GTAO → Bloom → 16 点对数亮度测光/AgX → 原单元调色。高档反射材质附近启用半分辨率 SSR，最多 48 步；其 beauty 作为主颜色输入，避免覆盖 TAA。
- TAA：8 个 Halton 抖动采样、世界深度重投影、邻域限幅、深度不连续/越界拒绝、切镜/尺寸变化清空历史。**没有逐物体速度缓冲**，运动植被依靠限幅抑制拖影，不能视为商业引擎的完整 TSR。
- 高度雾为 8 步密度积分和米氏方向散射；远山保留空气透视。**没有体积阴影贴图/多次散射**，不能宣称已完成遮挡正确的体积光柱；室内继续使用已有窗光。
- 亮度测光每 24 帧异步读取 1 像素，曝光在 0.72–1.35 倍间以不同明暗适应速度渐变。回忆显形不启用 override-material 的 AO/SSR，防止未重现的物件投出幽灵遮蔽；它们仍共用 HDR、物理环境、TAA、测光和调色。
- `tools/world-quality.html`：正式游戏嵌入、机位记录、渲染通道诊断、120 帧窗口记录。正式游戏 `?perf=1` 的浮层统计整帧绘制次数。
- 新增程序计算/着色器，**未下载外部美术素材**。Three.js 自带 Sky/CSM/GTAO/SSR 源代码使用 Three.js MIT 许可证，不是来源不明的美术资产。

## 测试

### 1. 光照与大气

完整 npm test（777 项前端 + 7 项 Python）、npx tsc --noEmit、npm run build 通过。新增太阳时/方向、曝光渐变及上下限、物理天空系数、CSM 保留原着色器回归。

固定默认地图机位，浏览器 1280×720：改前约 8.9–10.2 ms、ratio 1；改后约 13.9 ms、EMA 15.8 ms、ratio 1（72 fps）。这是当前开发机的帧间隔采样，不是所有设备 60 fps 的保证，也不是 GPU timer。启动编译帧另计。

截图：`quality-shots/01-light-before.png` 与 `01-light-after.png`；`00-hero-pending.png` 是未交付提示的验证。后续仍需实际手机、多个单元、长时间运动、透明材质和全部剧情逐项验收。

### 2. 地形与远景（需求 / 接口补充）

整张地图改为 12×14 块，外加一圈地形延伸覆盖边缘；high/med 块内 32/16/8 段，low 16/8 段。按相机距离 90/210 m 切换，12% 迟滞；网格边缘有 1.4 m 裙边。共用地形高度函数、跨块差分法线与世界坐标纹理，保证不同细分块接缝连续。寻路和地面点击改成遍历实际地形块，角色地形高度函数保持一致。

近处五层地形材质增加两次有界高度视差采样，14–65 m 渐隐、最大厘米级偏移，低档禁用；岩石保留三向投影、湖岸保持湿润混合。现有两层侵蚀山脉、林带和雪线继续使用，外延地形衔接山脚。程序生成，无新增外部素材。

验证：779 项前端测试 + 7 项 Python、TypeScript、生产构建通过。新增不同细分相邻地块的高度/法线一致、裙边/范围与可行走高度不变测试。截图 `02-terrain-before.png` / `02-terrain-after.png` 为相同默认机位；改前采样 18.4 ms、ratio .75，改后 15.6–17.1 ms、ratio .75，短窗口结果存在动态植被/负载波动。没有据此声称普遍性能提升。近地表起伏和移动接缝仍需更多机位验收。

### 3. 植被（需求 / 接口 / 验证补充）

高档草格从 1.1 m 加密至 0.8 m，中档 1.5→1.1 m；每簇改为 12 片更窄的弯曲草叶（低档 9 片），降低枯黄比例和实例过亮补偿。仍为 GPU 实例化、玩家附近铺设与距离连续收缩；增加受天气风力驱动的风摆和微弱逆光透光，远处用同层草地表色衔接。

树皮/叶片原有程序 PBR、叶脉法线、镂空透光、风和对应阴影保留。`distantLeafCards` 增加 160 m 外第三档叶冠：稳定抽样约三分之一叶片并扩大卡片保持冠幅，复用原 UV/法线/颜色/摆动。LOD 有迟滞，逐实例视锥剔除之外增加三点地形遮挡，仅遮挡高于冠顶视线 3 m 的远树，近处不剔除；这是地形遮挡，不是完整建筑 GPU 遮挡查询。无新外部资产。

781 项前端 + 7 项 Python、TypeScript、构建通过。新增远冠预算/属性保留、地形遮挡对可见冠顶和近树的保护测试。默认同机位 `03-vegetation-before/after.png`：改前 12.5 ms（ratio .75），改后 12.5 ms、EMA 14.1 ms（ratio 1）；分辨率有自适应变化，不能把两个数当作严格同负载 benchmark。

### 4. 水面、道路、建筑（需求 / 接口 / 验证补充）

`WaterCapture` 为近处 65 m 内最近的水平水面提供同场景反射/水下折射（high 512²、med 256²、low 环境反射回退），每 4 帧最多更新一对 HalfFloat 图。镜像相机与水面裁剪平面、波纹扭曲 UV、菲涅尔、深度吸收及岸边泡沫组合；捕获时隐藏全部水面防止递归，结束或异常均恢复可见性、剪裁、渲染目标、XR 与阴影状态。移远后清除捕获有效标记；共享材质按平面高度限制使用。主地图和已完整重现的回忆水面共用此路径。

道路增加磨损去饱和、接缝低洼积水遮罩及局部粗糙度/法线抹平，接入 `surfaceClimate.wet` 后随雨湿变化。建筑保留已有窗、檐口等几何和程序 PBR，新增近景细裂纹，并将墙根污渍改为中性灰绿；**未重建所有建筑资产**，几何细节仍受原场景建模水平限制。未引入新外部美术资源。

784 项前端 + 7 项 Python、TypeScript、构建通过。新增镜像相机的方向/位置、克隆材质捕获键、异常时渲染状态恢复测试。`04-water-before.png` / `04-water-after.png` 使用相同 1280×720 水面预览机位，可见岸线与天空由真实场景捕获进入水面。主世界观测约 15.6 ms，但本次应用窗口变成了 1310×1141，该主世界截图不作为严格同机位比较；后续对照工具固定内部视口以避免窗口尺寸干扰。

### 5. 天气与时间（需求 / 接口 / 验证补充）

`SolarClock` 提供跨午夜最短路径的太阳时渐变；黄昏对齐 18:30、夜晚 22:00，其他天气 14:00。太阳方向、CSM、昼夜环境亮度、星点与路灯共同变化，避免“夜晚只把颜色压暗、太阳仍在正午”的情况。地图新增收起式天气与太阳时刻控制，回忆保留脚本驱动的平滑天气和室内窗雨。

`WeatherHeightField` 在相机周围用 32² HalfFloat 高度纹理采样地面，2 m 网格移动时才重建；雨雪裁切和水花落点使用实际起伏地形，室内继续用固定地面和窗玻璃雨痕。`surfaceClimate` 将湿润、雨量、时间接至道路遮罩；地形、草、道路和建筑跟踪湿润色/粗糙度，跳过蒙皮及人物子树，草的透光乘太阳能量防止夜晚发亮。雨停后按已有天气状态机缓慢变干。

786 项前端 + 7 项 Python、TypeScript、构建通过。新增高度缓存坐标/复用、太阳时跨午夜连续性测试；保留原有晴雨雪互斥、雨窗和湿润恢复测试。`05-weather-clear/rain/night.png` 是固定内部 1280×720 视口、同一机位的天气状态对照（不是全部场景的旧版本/新版本截图）。雨天约 13.9–14.3 ms，夜晚采样 25.7 ms；夜晚尚未达到 60 fps，接下来性能项需处理阴影/反射峰值。

### 新增画质要求

用户追加桌面 2K。按 2560×1440 QHD 目标实现，保持世界窗口原始宽高比，始终显示实际绘制缓冲像素；画质优先模式不得悄悄用低像素画布冒充 2K。手机保持自动降档。2K 与 60 fps 分别验收，不能以增加像素数量代替美术质量，也不能把单次高帧数当作全场景保证。
