# 游戏设计文档：《词场冒险 · 2090 回溯：我的大学》

> 这是一款**游戏**，不是学习软件。玩家学习《大学英语读写教程 3》的 130 个词汇和 18 篇文章，
> 方式是：2090 年的“我”回溯 2026 年的大学记忆，世界随英语声音缓慢建立，我触碰它、看着当年的自己、附身重新经历它。

## 1. 核心设定：2090 年，一次记忆回溯

- **时间**：2090 年。男主已经老了，但还活着。科技很发达：城市安静、干净、几乎不需要人开口；神经接口可以把一个人的意识送回他自己的记忆里。
- **基调**：带一点伤感。不是悲剧，是一个老人在很好的时代里，想回去看看那个笨拙、年轻、还在学英语的自己。
- **开场**：雨夜，2090 年的公寓。柔和的界面光，窗外悬浮交通无声流过。他把手放在“记忆回溯”接口上，系统用平静的声音问：
  *“Destination: 2026. University. Are you ready?”* —— 意识下潜。
- **世界随英语声音建立**：回溯一开始，世界是空的——一片带微光的雾。系统开始用英语朗读那段记忆（就是文章的句子），
  **每一句话说出来，世界就长出一块**：说到 *library courtyard*，石板从光点里拼出来，庭院的树一层层长出叶子；
  说到 *conversation club*，一间教室的墙从地面升起，桌椅落位，窗外的光照进来。说到某个单词时，那个词对应的物件从“记忆的洪流”
  （流动的光粒和半透明的英文字母）里凝结成形。世界是**缓慢地**建立起来的，像想起一件很久以前的事。
- **“我在看我上学”**：年轻的他（2026，大学生）在回忆里是一个角色；年老的他（2090）是旁观者，能走近、能触碰，偶尔也能“附身”回年轻的自己。
- 文章里的 Lin、Mei、An、Rui 是他大学时的同学和朋友；“the club / the class / students” 就是“我们”。
- **单词不是背景，单词是记忆里的东西**：`notification` 是床头那部亮起来的手机，`luggage` 是第一次独自出发时那只太轻的背包，
  `lunar` 是控制室屏幕上那块灰白的月面，`inflation` 是书店账本上被红笔圈出的房租。每个词都有一个能看见、能拿起、能用的实体。
- **玩家**就是 2090 年的他。

## 2. 三种人称 + 二维平面

| 体验 | 谁在说话 | 镜头 | 玩家在做什么 | 学到什么 |
|------|----------|------|--------------|----------|
| **第二人称 · 回溯系统**（你） | 回溯系统用英语对 2090 年的他说话：“You remember a courtyard. Reach for it.” | 跟随镜头，玩家角色是 2090 年的他（半透明、带一点微光的身影） | 在正在成形的记忆里走动，**触碰**从洪流里凝结的物件；触碰让物件稳定下来，并说出它的词 | 词形、发音、词义（识别） |
| **第三人称 · 我在看我**（他） | 文章原句：“A campus conversation club met each Thursday…”（系统朗读，世界随句子建立） | 电影镜头：宽银幕黑边、机位运镜；年轻的他和同学在表演那段往事 | 看着自己上学。**记忆会断片**：一句话少了一个词，画面里三个物件在闪，选对那个，记忆才接得上 | 语境中理解（阅读、完形） |
| **第一人称 · 附身**（我） | 年轻的他的内心独白：“I counted three notifications before I realised nobody had spoken.” | 第一人称，用 2026 年那双眼睛看 | 附身回年轻的自己，在关键时刻替他开口：同学问了一句话，你用一个词回答 | 产出与运用 |
| **二维 · 旧笔记本**（纸上） | 2026 年他亲手写的课堂笔记、日记、车票背面 | 平面纸张，背景是虚化的记忆世界 | 笔记被时间晕开了，用词块把它补全；或在漫画格 / 横向卷轴里玩小游戏 | 句子构造、翻译、写作 |

### 每段回忆的节奏（约 6–10 分钟）

1. **下潜**（第二人称）：2090 年的他触碰单元记忆点 → 雾 → 系统开始朗读，世界随英语一句一句地建立（3–5 句，约 1 分钟）。
   洪流里凝结出 5–8 个物件，你走过去触碰它们，记忆变稳定。
2. **我在看我**（第三人称）：年轻的自己和同学出现，电影开始。文章逐句朗读、字幕、场景继续生长；2–4 次“断片”。
3. **附身**（第一人称）：在转折点，镜头推进到年轻的他眼里，你替他做 2–3 个选择。
4. **旧笔记本**（二维）：他那天的笔记，几行被晕开，用词块补全。
5. **定格 · 上浮**：回忆完整，画面定格成一张泛黄底片，慢慢淡回 2090 年的公寓。窗外下着雨，他轻声说一句英文。
   2026 年的校园地图上，这段回忆所在的地方永久亮起。

## 3. 18 段回忆（世界观）

| 单元 | 回忆 A | 回忆 B | 回忆 C（中国故事） | 二维玩法 |
|------|--------|--------|--------------------|----------|
| 1 数字时代 | **周四的沉默**：图书馆庭院边的会话社，满屏通知却没人开口；我们做了四周的倾听实验 | **床头的光**：天还没亮，通知点亮设备，我刷了二十分钟；算法替我挑选了世界 | **山那边的诊室**：山区卫生院和沿海医院的远程问诊，奶奶第一次对着屏幕说话 | 手机屏幕上的消息流：把被算法打乱的句子拖回正确顺序 |
| 2 人生故事 | **两种人生，一个转折**：校史档案馆的展览，我们用证据找人生的转折点 | **天使的另一面**：赫本肖像背后的慈善档案，我们为她布展 | **郑和的海图**：海图室里复原七下西洋 | 展板拼贴：把传记片段按时间排好 |
| 3 出发吧 | **旅行的意外目的**：清单上的地标，和计划外的那条小巷 | **一个人出发**：Mei 第一次独自出远门，车站大得吓人 | **成都到西安的高铁**：Lin 研究的那条路线 | 横向卷轴：车窗外的风景，按行程跳过词语站台 |
| 4 当工作成为乐趣 | **什么让工作有意义**：职业工作坊里的争论 | **小提琴作坊**：师傅让学徒量一条几乎看不见的缝 | **苏州绣坊**：绣娘手里的丝线 | 绣绷：按图样穿针，把词绣进花纹 |
| 5 航天梦 | **月球背面**：任务展上的空白月图 | **鹊桥中继**：控制室模拟，帮探测器把信号送回地球 | **航天员的日常**：科学中心里的训练舱 | 轨道小游戏：拖动中继卫星保持信号链路 |
| 6 经济 | **港口书店**：经济衰退中的 Lantern Books | **书的共享**：社团的换书柜 | **云河县图书馆**：经济下行时的阅读 | 账本：配平收入与支出，填对经济词 |

## 4. 单词即物件（130 个）

- 每个词在 `memoryObjects` 表里有：`archetype`（外形原型，约 24 种：屏幕、信件、书、钥匙、灯、背包、车票、地图、齿轮、天平、种子、乐器、工具、星图……）、
  `pose`（摆在哪：桌上 / 墙上 / 地上 / 手里 / 悬空）、`verb`（触碰时的小动画：亮起、翻开、转动、发声、展开）、`line`（第二人称旁白一句，含该词）。
- 物件外观写实（沿用写实化成果的材质），上面**不贴字**；靠近时浮现一枚小小的词签（词 + 音标），触碰后词签展开成一行：中文义 + 一句话，2–3 秒后自动收起。
- 同一个词在 A/B/C 三段回忆里可能以不同物件出现（`mission` 在单元 2 是一封任务信，在单元 5 是任务徽章）。

## 5. 界面原则（不挡场景）

- 默认**没有大面板**。屏幕上只有：底部字幕条（电影模式）、右上角小小的视角标记（你 / 我 / 他们 / 纸）、左上角记忆匣图标（已收集词数）。
- 题目都变成场景里的动作：选择题 = 点画面里的物件；完形 = 胶片卡住；对话 = 第一人称对话选项（贴在画面下方三行以内）。
- 原有的学习面板（语法工坊、记忆远征、复习）收进“记忆匣”，需要时再打开；不再在进入单元时弹出。
- 手机竖屏：字幕和选项不超过屏幕下方 30%；二维手账占满屏但背景是虚化的三维场景。

## 6. 进度与奖励

- 每段回忆完成后：场景永久变化 + 一张“记忆底片”（定格截图风格的卡片，可在记忆匣里重看电影）。
- 记忆匣里每个词有“清晰度”（模糊 → 清晰 → 闪光），由间隔回访决定；模糊的词会在场景里以褪色物件重新出现，触碰它就是复习。
- 现有 XP / 徽章 / 存档沿用。

## 7. 技术方案概要

| 模块 | 职责 |
|------|------|
| `memory/MemoryScript` | 回忆脚本数据格式：场景布置、节拍（beats）、字幕、物件、任务、视角切换 |
| `memory/MemoryRunner` | 按节拍推进；监听玩家动作；保存进度 |
| `memory/CinemaDirector` | 宽银幕黑边、机位轨道、字幕时间轴、朗读、定格 / 胶片卡住效果 |
| `memory/PovRig` | 三种相机：第二人称（现有跟随）、第三人称电影机位、第一人称（环顾、轻微呼吸晃动） |
| `memory/Materializer` | 世界随声音建立：物件 / 建筑从光粒洪流中凝结（溶解显形着色器 + 粒子流 + 飘散的英文字母），按句子分组逐步显现 |
| `memory/prologue2090` | 2090 年公寓开场与每段回忆结束的上浮 |
| `memory/Interaction` | 射线拾取 / 凝视、物件高亮描边、词签浮现 |
| `memory/memoryObjects` | 130 词 → 物件原型 / 动作 / 旁白 |
| `memory/actors` | 回忆中的人物（复用现有 NPC 身体），简单表演：走位、坐下、转头、手势 |
| `memory/paper2d` | 二维手账层：纸张 / 漫画格 / 横向卷轴，Canvas 2D 绘制 |
| `memory/hud` | 字幕条、视角标记、记忆匣、对话选项（极简） |

脚本的大部分内容由数据自动生成（字幕来自文章原句、胶片卡住来自含本单元词的句子、选择题干扰项来自同单元词），
每段回忆只需手写一份“舞台布置”（场景、人物走位、机位、物件位置、第一人称独白和选择）。
