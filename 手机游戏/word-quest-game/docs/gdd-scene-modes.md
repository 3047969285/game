# 双场景线设计：文章演绎 × 词造世界

> 2026-10-22 · 依据用户方向：**读写 3 按文章实时演绎；CET 4/6 用单词自由组合建造世界；科技化记忆风、少提示、沉浸。**

## 1. 两条线，两套逻辑

| | 读写 3 · 文章演绎（回忆线） | CET 4/6 · 词造世界（建造线） |
|---|---|---|
| 入口 | 地图 → 单元记忆点 A/B/C → 进入回忆 | 地图右下 ✦ → `WORDWORLD · CET` |
| 核心输入 | **文章句子**（逐句朗读） | **玩家自由挑选的单词**（2–4 个） |
| 世界如何出现 | 随朗读逐句显形（物件的词来自文章） | 选词后按角色/语义生成配方，**一次性建造** |
| 玩家角色 | 2090 年的他，回溯 2026 | 词场的建造者（无角色叙事） |
| 提示 | 极少：默认英文字幕，中文按需开；自由触碰不弹完整词签 | 几乎无提示：只有选词槽与 BUILD |
| 视觉 | 深空冷光记忆质感（扫描线/边缘光/宽银幕） | 深空 + 地形线框 + 发光结构 + 悬浮词 |
| 进度 | 记忆点、记忆匣、词汇清晰度 | 已建造世界数（本机 `word_quest_wordworld_v1`） |

## 2. 文章演绎（读写 3）的调整

1. **按文章实时演绎**：回忆脚本继续由 `autoScript.ts` 从段落切幕（`buildActs`），每句都落在一幕里；
   朗读一句，世界长一块；断片只在文章关键句出现。导入教材原文时沿用同一条管线（只换 passage）。
2. **科技化记忆风**：回忆舞台加 `mem-tech` 类——细扫描线、冷色调、边缘光词签、HUD 字距拉大；
   宽银幕黑边保留。不是“学习面板”，更像一段神经回放。
3. **少提示**：
   - 中文字幕默认关闭（点击 ZH 才开），默认纯英文沉浸；
   - 自由触碰（`touch` 拍）不显示完整词签，只留一个微小边缘光点，靠近/凝视才浮出；
   - 断片（`gap`）仍显示候选词签——这是玩法本身，不是提示；
   - POV 角标、退出、摇杆保持极简，不加常驻面板。
4. **沉浸**：字幕/选项合计 ≤ 屏幕下方 30%，进入回忆时黑场下潜，结束定格。

## 3. 词造世界（CET 4/6）的逻辑

```
单词（2–4 个） → 角色分类（◇ 物件 / ↻ 动作 / ✦ 性质）
              → 世界配方（地形 / 天气 / 结构 / 调色 / 种子）
              → Canvas 沉浸场景（地形 + 发光结构 + 悬浮词 + 扫描线）
```

- **角色**：词性优先（n./v./a./ad.），释义关键词兜底，最后按哈希兜底——任意词都能参与建造，不卡玩家。
- **地形**：物件词关键词（山/海/森林/城/沙/岛/田/天空）决定；无匹配时按种子选。
- **结构**：动作词决定塔/路/图书馆/家/市场/桥/观测站/墙/花园/门；水地形自动加桥，城自动加路。
- **天气/调色**：性质词决定晴/黄昏/夜/雨/雪/暴风/雾，以及天空、地面、水、发光色。
- **确定性**：同一组词（与顺序无关）永远生成同一世界（FNV-1a 哈希做种子），可分享/重复进入。
- **自由**：不设“正确组合”；语义越明确，世界越可读；不明确的词也会长出东西（记忆/词场的随机性）。
- **少提示**：界面只有三个槽（◇↻✦）、BUILD、已建造数量；不解释规则、不弹教程。
- **进度**：已建造世界的种子存本机 `localStorage`，显示 `WORLDS · N`；不参与 RW3 存档。

## 4. 验收

- RW3：进入回忆默认英文字幕；自由触碰不出现完整词签；画面有扫描线/冷光质感；文章逐句显形不被提示打断。
- CET：地图 ✦ 打开 WORDWORLD；选 2–4 个词 → BUILD → 场景立即出现；同词同世界；`WORLDS` 计数增加；关闭后回到地图。
- 代码：`npx tsc --noEmit`、`npx vitest run` 全绿。
