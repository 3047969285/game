# 主世界操作、清晰度与移动修复

## 产品需求说明书

电脑浏览器与手机共用第三人称相机、移动规则、灵敏度与碰撞。电脑可启用鼠标锁定后直接上下左右环顾，Esc 释放；不支持锁定的嵌入浏览器保留按住拖动。手机用拖动环顾、摇杆移动。修复拖拽同时触发点击寻路、拖动松手后强制回正、超快步速与角色上下抖动、穿过建筑，以及晴天画面泛灰的问题。人物模型、脸、头发、服装仍由 Claude 负责，本轮仅修改世界控制与关节动画驱动。

## 接口文档

- `ExplorerCamera.applyLookDelta(dx,dy)` 是鼠标相对移动与触屏拖拽的共同入口，使用同一灵敏度、俯仰限位和第三人称跟随距离。手动环顾后保留方向，WASD/摇杆按当前镜头朝向移动。`bindDrag` 创建桌面鼠标入口，拒绝锁定时提示拖动；窗口失焦、打开设置、暂停、销毁均释放锁定，销毁移除文档事件。手机不显示锁定入口。
- 点击寻路在抬手时判断：移动超过 10 CSS 像素就取消点击；即使拖回原点，也不触发寻路。锁定视角时点击画面不触发寻路，E 仍用于水晶交互。
- 晴天删除固定半透明雾平面；主世界 `hazeStrength:0–1`（默认 .35）在环境设置即时生效，统一缩放材质雾与后期空气透视。天气仍平滑驱动相对雾量。探索调色不再抬黑、叠扫描线或色差，降低冷色染色，保留单元主题色；Bloom 强度约为原来的 .32，HDR 阈值 1.2。保持真实 QHD 像素策略，未把锐化放大当作高清。
- `PlayerController` 默认快步行走 2.2 m/s、奔跑约 4.07 m/s，速度用 .12/.08 秒指数响应平滑起停；`speed` 返回碰撞后的实际位移速度，停止/失焦清空输入。每帧先移动，再让相机跟随同一显示位置；脚下高度按显示位置采样，移除原整个人上下 6 cm 弹跳。
- `WorldCollision` 按 12 m 网格缓存静态网格，重建地标/装饰后更新索引，不每帧遍历场景。附近实际三角形射线检查保留门洞；每次位移分成不超过 .18 m 的小步，使用 .32 m 半径、多个身体高度/横向采样探测，沿墙投影剩余位移。地面向下检测支持 .36 m 以下台阶。树干/岩石实例使用简化圆柱碰撞代理，不重复渲染；透明建筑玻璃可碰撞，水面/光效/叶片不作为实墙。相机沿视线收缩，避免直接穿墙。这个实现是静态角色控制近似，**不是完整刚体物理、逐肢体碰撞或坡地双脚 IK**；复杂凹角/低矮几何仍需更多场景检查，水域未新增游泳玩法。
- `Locomotion` 按实际行走距离推进周期，步行站立支撑相约 62%，奔跑约 46%；屈膝抬脚、脚踝补偿、对侧摆臂、肘部自然弯曲和小幅躯干反向扭转，起停连续混合。顶墙实际速度为零时步态回到站姿。已有 GLB idle/walk 混合保留；本轮没有新增动捕素材，不能宣称已等同真人动捕。
- 手机设置面板按游戏容器高度约束，不再因桌面窗口高度计算而裁掉“返回游戏”。没有新增外部美术或动作素材。

## 测试

新增/扩展 ExplorerCamera 输入一致性、锁定释放和事件清理测试；PlayerController 平滑速度与撞墙实际速度测试；Locomotion 按位移推进及停步测试；WorldCollision 冲刺撞墙/滑动、门洞、台阶、玻璃/水面区分、相机收缩与 2000 树干代理索引测试。完整 npm test、TypeScript 与生产构建结果见本轮提交记录。

浏览器实际验证：当前嵌入浏览器拒绝 Pointer Lock 时显示拖动回退，原生拖动可以同时改变水平/垂直视角且不自动回正；390×844 布局中摇杆、设置、返回按钮可见。仅是手机尺寸/共享输入测试，尚未作实体手机性能验收。晴天图 `10-clarity-after.png`、鼠标环顾图 `11-mouse-look.png`、手机设置图 `12-mobile-settings.png`。`10-clarity-before.png` 采集时应用窗口宽高比不同，仅作旧画面参考，不作为严格同机位性能对比。曾有旧热更新预览无法响应，已在新预览完成验收；无据此编造旧窗口的错误原因。
