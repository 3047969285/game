# 产品需求说明书：人物自然度

用户要求人物具有可信的人体、面部表情与衣服细节，减少假人感。原程序化模型存在眼窝穿插、肩袖断层、衣服敞口和面部微动累积问题。本轮将玩家与回忆演员的默认可见身体换成 Microsoft Rocketbox 的两套真人比例蒙皮模型，保留原剧情动作控制接口。

## 范围与验收

- 男女两套基础外观，包含连续身体蒙皮、皮肤与服装贴图、头发、衣领、门襟、拉链、褶皱；本地提供资源，不依赖外部头像服务。
- 眨眼、轻微视线移动、眉部变化、嘴角微笑和讲话开合使用模型面部 morph targets。嘴部为程序化谈话节奏，尚非按音素同步口型。
- 站立、坐姿、阅读、看手机、伸手和行走继续由原骨骼姿势控制器平滑插值，适配到模型绑定轴；头部微动持续播放必须有界。
- 主世界玩家与回忆第三人称玩家使用同一真人模型，回忆玩家保留冷色轮廓和第一人称隐藏。普通静态场景 NPC 保留原低成本路径。
- 模型加载失败时保留程序化兼容身体。原 SDF 头顶和肩部采样边界、衣物细节仍修复，作为回退路径。
- 模型原始版权和 MIT 许可随资源分发；来源记录在 public/models/humans/SOURCES.md。

## 预算和已知边界

男性模型 8,684 三角面、女性 8,308 三角面，各 3 个可见材质批次；道具另计。两份 GLB 合计约 9.2 MB，包含贴图及 67 个面部形变。首次按本地资源加载，之后复用模板；实例独占骨骼、几何和材质，共享不可变纹理。

当前两套基础外观使用资源原有衣服，脚本 outfit / shirt 配色继续作用于回退身体，不表示可任意替换真人服装。现阶段不承诺照片级数字人、个人肖像或完整换装系统。
