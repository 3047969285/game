# 单元 6《经济：日常生活背后的力量》场景清单

> 对应代码：`src/features/memory/stages/{bookstore,bookExchange,countyLibrary}.ts`、`scripts/u06.ts`。

## A《在衰退里活下来》
- 舞台 `bookstore`：老港区 Lantern Books；书架、柜台、账本、租金单、价签、台灯、窗外街道。
- 人物：年轻的“我”、Lin（店主）。
- 机制：建书店 → 触碰物件 → 文章逐句演绎 → 断片落在“账本上被圈出的那一项”。

## B《书的共享》
- 舞台 `bookExchange`：校园社团活动室；交换书架、纸箱旧书、规则卡、笔记本电脑、印章。
- 人物：年轻的“我”、An（组织者）。
- 机制：建换书角 → 触碰物件 → 文章逐句演绎 → 断片落在“换书的规则”。

## C《云河县图书馆》
- 舞台 `countyLibrary`：虚构县城图书馆阅览室；旧木桌、报纸架、少儿书架、借阅本、旧风扇、捐赠箱。
- 人物：年轻的“我”、Mei（读者）。
- 机制：建阅览室 → 触碰物件 → 文章逐句演绎 → 断片落在“书从哪里来”。

## 验收
- 三篇通过 `validateScript`，所有部件显形；默认纯英文字幕、极简 HUD。
