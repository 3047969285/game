# 单元 3《出发吧》场景清单

> 只写我们自己的场景设计；课文文本由玩家导入教材包后在本机替换。
> 对应代码：`src/features/memory/stages/{travelLounge,soloStation,highSpeedTrain}.ts`、
> `src/features/memory/scripts/u03.ts`。

## 记忆点 A《旅行的意外目的》

| 项 | 设计 |
|---|---|
| 舞台 | `travelLounge`：小城旅店前厅/旅行角，傍晚 |
| 人物 | 年轻的“我”、Rui（同行/旅店老板式的向导） |
| 关键物件 | 地图墙、行程单、柜台、明信片、旧相机、行李箱、长椅、台灯、挂钟、窗外街灯 |
| 光线 | 傍晚暖光 + 台灯，安静的旅店 |
| 机制 | 建前厅 → 触碰物件 → 文章逐句演绎 → 断片落在“清单之外的那条小巷” |

## 记忆点 B《一个人出发》

| 项 | 设计 |
|---|---|
| 舞台 | `soloStation`：夜晚的火车站大厅，层高 4.2 米 |
| 人物 | 年轻的“我”、Mei（第一次独自出远门） |
| 关键物件 | 发车屏、检票闸机、长椅、行李箱、纸质车票、售票亭、立柱、挂钟、站台窗、顶灯、导向牌 |
| 光线 | 冷白的站厅灯 + 站台窗外的夜色；人显得很小 |
| 机制 | 建站厅 → 触碰物件 → 文章逐句演绎 → 断片落在“她确认了两次的那张票” |

## 记忆点 C《成都到西安的高铁》

| 项 | 设计 |
|---|---|
| 舞台 | `highSpeedTrain`：G 字头列车的一节车厢，下午 |
| 人物 | 年轻的“我”、Lin（去看表姐） |
| 关键物件 | 两侧车窗、座椅与小桌、车票、手机、行李架、过道、顶灯、车厢门、流动的风景 |
| 光线 | 午后的光从两侧窗进来，车厢里很亮 |
| 机制 | 车厢静止、窗外景观向后流动（`animate`）→ 文章逐句演绎 → 断片落在“到站/换乘/时间”节点 |

## 验收

- 三篇均通过 `validateScript`，且所有舞台部件都会在演绎中显形（`scripts.test.ts` 的 unit3 覆盖测试）。
- `highSpeedTrain` 的窗外景观有持续动画；车厢本身不动，避免晕动。
- 默认纯英文字幕、极简 HUD、科技记忆质感。
