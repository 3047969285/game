# 单元 2《人生故事》场景清单

> 只写我们自己的场景设计；课文文本由玩家导入教材包后在本机替换。
> 对应代码：`src/features/memory/stages/{archiveExhibit,hepburnGallery,chartRoom}.ts`、
> `src/features/memory/scripts/u02.ts`。

## 记忆点 A《两种人生，一个转折》

| 项 | 设计 |
|---|---|
| 舞台 | `archiveExhibit`：2026 年，校史档案馆临展厅 "Lives in Motion"，闭馆后的安静 |
| 人物 | 年轻的“我”（看展）、Lin（讲解/策展） |
| 关键物件 | 展板、时间线、两个玻璃展柜、投影幕、档案架、长桌、长椅、射灯、木箱 |
| 光线 | 冷白展灯 + 投影暖光，窗外傍晚 |
| 机制 | 建展厅 → 触碰物件 → 两个人物生平按段落逐句演绎 → 断片放在“转折点” |

## 记忆点 B《天使的另一面》

| 项 | 设计 |
|---|---|
| 舞台 | `hepburnGallery`：学生为 Audrey Hepburn 布置的小展厅 |
| 人物 | 年轻的“我”、Mei（策展） |
| 关键物件 | 肖像、老电影海报、玻璃展柜、小黑裙人台、UNICEF 信、长椅、投影、射灯、铜牌 |
| 光线 | 暖白射灯、低照度，像傍晚的展馆 |
| 机制 | 先看见“熟悉的肖像”，再在展柜/信里发现“另一面”；断片考“哪件物品对应哪段人生” |

## 记忆点 C《郑和的海图》

| 项 | 设计 |
|---|---|
| 舞台 | `chartRoom`：傍晚的海图室，窗外是江面与宝船 |
| 人物 | 年轻的“我”、 organizer（讲解者） |
| 关键物件 | 长桌上的海图与罗盘、卷轴、宝船模型、望远镜、黄铜灯、木箱、墙上航线图、海景窗 |
| 光线 | 暖橙夕光从窗外来，室内木头与黄铜反光 |
| 机制 | 文章把“航行”讲成时间/空间顺序；断片放在“先到哪、后到哪”的节点上 |

## 验收

- 三篇均通过 `validateScript`，且所有舞台部件都会在演绎中显形（`scripts.test.ts` 的 unit2 覆盖测试）。
- 默认纯英文字幕、极简 HUD、科技记忆质感；手机竖屏可用。
