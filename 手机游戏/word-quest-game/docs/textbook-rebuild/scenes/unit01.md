# 单元 1 场景清单（样板块）

> 只写我们自己的场景设计：地点、时间、人物、光线、物件、段落对应与游戏机制。
> 不复制课文原句；课文文本由玩家导入教材包后在本机替换。
> 对应代码：`src/features/memory/stages/*.ts`、`src/features/memory/scripts/u01*.ts`。

## 1. 记忆点 A《周四的沉默》（Text A）

| 项 | 设计 |
|---|---|
| 舞台 | `clubRoom`：图书馆庭院边的社团教室，傍晚 |
| 段落 | 全文 20 句，按段落切成 4–5 幕 |
| 人物 | 年轻的“我”、Lin、Mei、An、Rui（老师缺席） |
| 关键物件 | 手机、消息屏、实验烧瓶、话题卡、咖啡杯、设备排、数据线、挂钟、空椅子、指南针、扩音器 |
| 光线 | 低角度暖阳从庭院窗照进来；室内略暗，屏幕冷光 |
| 机制 | 下潜建教室→触碰 6 件物件→五幕逐句演绎（他/我/纸）→每幕一次断片→定格 |
| 科技记忆感 | 宽银幕、边缘光词签、扫描线；自由触碰不弹完整词签 |

## 2. 记忆点 B《床头的光》（Text B）

| 项 | 设计 |
|---|---|
| 舞台 | `bedroomDawn`：2026 年大学宿舍，清晨 5:50 |
| 段落 | Text B 全文，按段落切幕 |
| 人物 | 年轻的“我”（坐在床沿看手机） |
| 关键物件 | 手机、床头柜、充电线、笔记本电脑、书桌、椅子、书架、海报、落地灯、地毯、窗外城市剪影、时钟、窗帘 |
| 光线 | 天未亮，窗外冷蓝；手机屏幕是唯一近光源；室内暖灯未开 |
| 机制 | 系统旁白两句话先点亮房间→触碰物件→文章逐句演绎→断片（选床头/桌面物件） |
| 与 A 的区别 | 不是“公共空间”，而是“私人清晨”：世界比人先醒 |

## 3. 记忆点 C《山那边的诊室》（Stories of China）

| 项 | 设计 |
|---|---|
| 舞台 | `clinicRemote`：山区乡镇卫生院诊室，雨后上午 |
| 段落 | 中国故事短文 + 翻译练习 |
| 人物 | 年轻的“我”、屏幕里的周医生、奶奶 |
| 关键物件 | 旧显示器、摄像头、药柜、检查床、凳子、海报、水壶、听诊器、路由器、窗外山脊、窗光、台灯、帘子 |
| 光线 | 雨后柔光从窗口进来；室内偏暖；屏幕冷光映在桌面上 |
| 机制 | 建诊室→触碰物件→短文逐句演绎→断片→Section C 翻译在“纸”视角变成中文讲述的英文重写 |
| 与 A/B 的区别 | 技术不是“上瘾”，而是“把远方的人接到眼前” |

## 4. 共通验收

- 每个场景的部件都能在 article 的句子/幕里显形，不出现永远看不见的部件（`validateScript` + `stageTargets` 校验）。
- 默认纯英文字幕（ZH 可开），自由触碰不出现完整词签；断片才显示候选词签。
- 每个场景至少 4 个电影机位，手机竖屏无键盘提示。
