# 单元 5《中国的航天梦》场景清单

> 对应代码：`src/features/memory/stages/{moonExhibit,controlRoom,astronautHall}.ts`、`scripts/u05.ts`。

## A《没有边界的探索》
- 舞台 `moonExhibit`：大学任务展；空白月面图、月球灯、着陆器与巡视器模型、任务徽章、展柜、星空窗。
- 人物：年轻的“我”、Lin（讲解）。
- 机制：建展 → 触碰物件 → 文章逐句演绎 → 断片落在“月面图上还没有名字的地方”。

## B《鹊桥中继》
- 舞台 `controlRoom`：校园任务控制室；大屏、控制台、中继卫星模型、天线、状态灯。
- 人物：年轻的“我”、An（任务负责人）。
- 机制：建控制室 → 触碰物件 → 文章逐句演绎 → 断片落在“信号被月球挡住之后怎么走”。

## C《航天员的日常》
- 舞台 `astronautHall`：科技馆训练区；舱体、航天服、程序板、检查单、跑步机、头盔、样本盘。
- 人物：年轻的“我”、Rui（讲解）。
- 机制：建训练区 → 触碰物件 → 文章逐句演绎 → 断片落在“程序里最普通的一步”。

## 验收
- 三篇通过 `validateScript`，所有部件显形；默认纯英文字幕、极简 HUD。
