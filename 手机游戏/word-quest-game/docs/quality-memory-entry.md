# 记忆回溯入口特效

## 产品需求说明书

用户希望进入记忆回溯时更有沉浸感。原入口直接切到黑色容器，再做黑场淡出，资源加载过程与场景出现缺少连续感。

本轮将入口组织为三个连贯阶段：原场景柔和失焦与暗下；青蓝/暖金光尘向中心汇聚，出现少量弧形拖尾、柔光环与记忆标题；新场景准备并渲染首帧后，从中心以柔边窗口展开。亮度保持克制，不做满屏白闪、剧烈抖动或快速缩放。原有场景配乐在显示回忆屏幕时平滑接续。

- 普通遮盖约 1.15 秒，展开约 1.05 秒；实际加载更慢时停留在低速呼吸画面，不假报百分比或提前显示空场景。
- 提供“取消回溯”和 Escape，返回单元后可以再次进入，不会点亮完成状态。
- 手机路径使用 64 个粒子、较低像素比和约 30Hz 绘制上限；桌面为 128 个粒子，像素比最多 1.5。加载等待时降至约 20Hz。
- prefers-reduced-motion 使用 360ms 遮盖、420ms 均匀淡出，不绘制运动粒子、光环、旋转文字或扩张窗口。
- 新入口覆盖旧的 1.4 秒黑场淡入，并将入口后的空场停顿缩短，避免堆叠等待。

## 接口文档

`MemoryEntryTransition({ title, onCancel? })` 创建一个独立于 World3D / MemoryStage 的临时 Canvas 2D 覆盖层。标题使用 textContent；不获取画布快照，不增加 WebGL 上下文、纹理或渲染通道。

- `covered: Promise<boolean>`：必须绘制完全遮盖的一帧后才返回 true；取消或提前清理返回 false。
- `cancelled: Promise<null>`：用户取消时解除模块加载的等待。App 用 Promise.race 立即返回，已发出的模型请求仅继续进入原有缓存。
- `reveal(): Promise<void>`：场景就绪后展开，重复调用复用同一承诺；结束或取消都会解除等待。
- `cancel()`：幂等取消，通知持有者销毁已创建的 MemoryStage，并清理覆盖层。
- `dispose()`：移除 DOM、键盘与尺寸监听、停止 RAF 并将画布存储缩至 1×1；重复清理安全。
- `MemoryStageOptions.onSceneReady?: () => Promise<void>`：prepare 完成、循环启动并经过首个渲染帧后调用；等待入口揭开再显示 gate / 开始旁白。取消后不得继续创建 gate。
- `drawMemoryEntry(ctx,width,height,frame,motes)`：确定性画面绘制；`memoryMotes(low)` 固定种子、64/128 粒子，不逐帧随机闪烁。

App 在原场景还可见时暂停 World3D 并创建覆盖层，同时导入回忆引擎和模型；待 covered 后切换到 memory 容器，构造舞台。成功、失败、取消均进入 finally 清理。全局音乐控件保持在覆盖层上方。

开发页 `tools/memory-entry-test.html` 可播放完整过渡、拖动展开进度、预览减少动态效果的静态画面。正式游戏使用同一绘制器和生命周期控制器。

## 测试

新增生命周期回归覆盖：完全遮盖后才发信号、慢加载等待、ready 后揭开、重复 reveal、取消解除承诺、RAF 与 Canvas 存储清理、手机像素比预算、reduced motion 无运动绘制、固定种子和粒子数量。舞台握手回归验证首帧先于入口揭开，揭开期间退出不会再创建开场 gate。

浏览器已实际检查：单元 A 入口失焦与标题、光环汇聚、展开后进入 3D 回忆；入场中取消立即回到单元卡片，随后可再次进入；正常进入后遮罩已移除，控制台无错误。生产构建预览确认首帧就绪后正常揭开，随后可点击开场 gate 进入回忆，控制台无错误。

不承诺真实手机硬件的帧率测量；低档预算由固定粒子数、像素比与绘制节流约束。

最终验证：45 个 Vitest 文件、586 项用例通过；7 项 Python 数据打包测试通过；TypeScript 检查与 Vite 生产构建通过。浏览器模拟 390×844 窄屏，标题区域 x=24、宽=342，位于可视宽度内；该结果是布局验证，不是真机性能测量。代码、接口说明、测试和构建产物一并提交至 memory-game 分支。
