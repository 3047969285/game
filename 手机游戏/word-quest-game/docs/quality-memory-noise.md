# 回忆场景噪音修复

## 产品需求说明书

用户反馈进入回忆后有很大噪音。代码检查发现旧 RainAmbience 会额外合成高频白噪声、低频粉红噪声和随机水滴，直接连接独立 AudioContext 的扬声器输出。开场与尾声均会启动，且不受配乐暂停、音量和旁白压低配乐的控制；这是已确认的额外噪声来源。

移除该噪声发生器及开场、尾声的启动路径。保留雨夜视觉、背景配乐、旁白和正常 UI 音效。现有页面需刷新以关闭旧页面已经创建的音频上下文。

## 接口文档

不新增外部接口。删除内部 RainAmbience 类和 StageDef.ambience 属性，场景声音继续使用现有 MusicPlayer 与 Narrator。配乐的暂停、音量、场景切换和旁白避让接口不变。

## 测试

增加开场 gate 与尾声的行为回归：旁白能解锁与朗读，且不会创建独立噪声音频上下文。保留公寓雨痕及动画场景测试，检查删除后无残余引用，并运行完整测试和生产构建。

此次原因来自播放链路代码定位；没有把代码检查声称为实际扬声器听音或用户设备测量。

验证结果：45 个 Vitest 文件、588 项用例通过，7 项 Python 测试通过；TypeScript 与 Vite 生产构建通过。记忆模块中 RainAmbience、makeNoise 与 createBufferSource 噪声链路引用均已清除。
