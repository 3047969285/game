# PRD：成片植被（树林、灌丛、碎石）

## 背景

主世界（全局单元地图）地形 720×880，现有装饰约 180 个零散物件（`World3D.rebuildDecor`）。
每个物件都是独立 Group，几何体逐个烘焙，数量一多就卡，所以只能压低数量。
结果是视野里大片空草地、几棵孤树，远处地平线只有雾，场景缺乏层次和细节。

## 目标

1. 主世界和单元世界里出现**成片的树林**：疏密有致，有林缘、林间空地，而不是均匀撒点。
2. 林下有**灌丛和碎石**，林缘有灌木过渡。
3. 地图边缘靠山处有**连续的远景林带**，填满地平线。
4. 帧率不明显下降：同一台机器上，高画质帧率下降不超过 15%，绘制调用增加不超过 12 个。

## 非目标

- 不改树木、灌木、岩石的造型本身（沿用 `props.ts` 的生成器）。
- 不做碰撞：玩家可以穿过植被（与现有装饰一致）。
- 不改星际 / 月面（`decorStyle === "space"`）主题：这些主题不生成树和灌木，只生成碎石。

## 需求

| 编号 | 需求 |
|------|------|
| R1 | 植被按林地密度场分布：低频噪声决定哪里是林地，林地内树密，林缘过渡到灌木，空地留白 |
| R2 | 不遮挡玩法：避开道路（距路中心线 < 7）、单元地标入口（半径 26）、湖面（湖椭圆放大 1.15 倍）、地图中轴线 |
| R3 | 远景林带：距地图边界 60 以内的区域密度提高，以针叶树为主 |
| R4 | 数量随画质档位变化：high / med / low 的总实例数比例约为 1 : 0.6 : 0.35 |
| R5 | 近处用精细模型，远处自动换成简化模型（LOD），切换距离约 70 |
| R6 | 视野外的实例不绘制（逐实例视锥裁剪） |
| R7 | 布局确定：同样的输入总是生成同样的布局（种子随机），切换单元再回来时布局不变 |
| R8 | 切换单元 / 销毁世界时释放全部几何体，不泄漏 |

## 验收标准

- A1 主世界观赏模式全景截图：能看到多片树林、林下灌丛、远处连续林带。
- A2 道路、入口、湖面上没有树。
- A3 浏览器控制台无报错。
- A4 高画质下帧率与改动前相比下降 ≤ 15%（同一台机器、同一视角测 2 秒均值）。
- A5 单元测试覆盖布局规划：确定性、避让区、画质比例、space 主题、边缘林带密度。
