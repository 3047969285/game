## C12 最终资产与画质（与 C11 并行，逐单元推进）

1. **kit 映射**：先用本地已有的 Poly Haven CC0 资产（51 个模型、9 套 PBR 材质、6 张 HDRI）把所有能映射的 kit 映射掉。映射写在 `kit_assets.json` 的 `kits` 里，这个文件 Codex 可以改。

   - Claude 会用 Blender 代码按画质标准建模，导出到 `Content/Memory/Props/`。

3. **贴花和杂物**：每个 set 至少 10 处贴花（CC0 污渍、磨损、纸痕），桌面和柜面上要有杂物。
4. **灯光**：每个 set 都要有体积雾、光束、手动曝光，CineCamera 用真实焦距和光圈。窗外不能是纯色，要用 HDRI 或真实景物。
5. **Fab**：现在卡在 Cloudflare 人机验证。不要绕过，写进“需要用户处理”。用户验证后再继续拉取免费的 Personal 资产。

## C13 沉浸式界面：去掉 UI，信息进入世界（重点，体验核心）

原则是**屏幕上几乎什么都不放**。所有信息都长在世界里，是这段回忆本身的一部分。

1. **字幕即回忆**：
   - 课文句子不放在底部字幕条。改成浮在空间中的冷光文字（`#ECEDE5` / `#B8D1D5`），用细等宽字体，随说话者或相关物件出现，读完后散成光尘消失。
   - 段落推进由玩家的视线或走动触发，不点“下一步”。
2. **单词即物件**：
   - 课文生词对应的物件，在玩家注视约 0.6 秒后，表面浮现一条冷光细线和单词、音标，下方是很淡的中文。
   - 按住或长按物件可以“记住”，记住时有轻微的脉冲和声音。
   - 不要弹窗，不要图标，不要按键提示。第一次出现时，用一行世界内的淡文字教一次就够了。
3. **练习即记忆断片**：
   - 题目以“断片”出现：世界去饱和、时间冻结，题干和选项变成浮在空中的几块玻璃碎片，选中后碎片合拢。
   - 答错时，回忆短暂失真（色差加噪点），然后恢复，不出现红叉。
   - 12 种题型都要有对应的断片表现。不要卡片式面板，不要彩色按钮。
4. **进度**：屏幕角落只保留一个极淡的“记忆完整度”细环，不显示数字和文字。暂停菜单是一个全屏、低对比的“记忆目录”，列出单元、文章和已找回的段落。
5. **穿梭转场（科技感回忆穿梭）**：
   - 布景之间、文章之间用转场：粒子化溶解、冷光扫描线、时间码倒数（2090 → 2026）、短暂的白噪音和低频声。
   - 时长 2–4 秒，可跳过。
   - 开场沿用 “MEMORY RECALL / Destination: 2026”。
6. **输入**：鼠标、手柄、触屏都要支持。触屏上注视改为点按，长按就是“记住”。
7. **测试**：PIE 自动化截图，覆盖横竖屏、每种题型的断片、字幕出现和消散、单词浮现、转场。界面元素计数要写进报告：除了“记忆完整度”细环，屏幕空间的 UI 必须为 0。
