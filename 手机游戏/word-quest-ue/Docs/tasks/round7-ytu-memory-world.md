## 世界结构

1. **2090 · 记忆之海（枢纽）**：
   - 老人闭上眼，四周是深色虚空，悬浮着一块块“记忆碎片”。每个单元一块，形状取自烟大的一处地标：钟楼、三元湖、七餐、图书馆……
   - 碎片里能隐约看到那个地方在 2026 年的样子（实时渲染的小窗口），碎片之间有细光丝相连。
   - 已经回忆起来的碎片明亮，没去过的碎片模糊。
2. **穿梭（时间和空间）**：注视并走向一块碎片后：
   - **时间**：钟楼的钟声响起（主题音）。碎片里的画面倒放，2090 年的痕迹逐层退去，年份数字从 2090 倒数到 2026，四季飞快流转一圈后停在这个单元的季节。
   - **空间**：玩家脚下最先“长”出地面，按 OSM 的真实位置向外扩散重建。路面和草地先出现；建筑从轮廓线框变成灰模，再变成真实材质，像照片显影；最后出现树、行人和声音（海风、鸟、远处操场）。
   - **2–4 秒完成**，全程是第一人称，不切镜头、不黑屏。
3. **记忆中的烟大（2026）**：
   - 按真实比例重建的主校区，用人眼视角自由行走。
   - 本单元的各个情景就是校园里的具体地点（门、教室、餐厅、宿舍）。
   - 课文里的人物是这些地点里的人，可以对话（接 DeepSeek）。
4. **离开**：画面定格、褪色，像一张旧照片。裂成碎片飞回记忆之海，这块碎片变亮。

### 技术方案（UE 5.8）

- **重建扩散**：
  - 全局材质参数集 `MPC_MemoryReveal` 里放重建中心（玩家位置）、半径和时间；
  - 所有场景材质接一个 `MemoryReveal` 函数：半径以外的部分是线框或灰模，加噪声溶解边缘；
  - 项目里已有 `MemoryReveal` 参数和 reveal 材质，要升级为按半径扩散。
- **碎片和粒子**：Niagara 负责碎片飞散和聚合，以及空气中的光尘。
- **时间倒流**：天空和太阳按年份、季节插值（HDRI 混合加天空大气）；画面在 2090 年偏冷灰，在 2026 年回到饱满的真实色彩。
- **声音**：钟楼钟声做转场主题；环境声分层淡入。
- **世界组织**：
  - 校园用 World Partition。地形、道路、水面和建筑体块由 OSM 数据程序化生成（`Tools/ytu_campus_build.py`，待写）；
  - 重点建筑（钟楼、图书馆、七餐、烟雨亭、玉带桥、校门、一个教学楼和一个宿舍）按照片精修；
  - 室内情景（客厅、教室、宿舍、餐厅）用 `room_shell.py` 那套方法，嵌在对应楼栋里。
