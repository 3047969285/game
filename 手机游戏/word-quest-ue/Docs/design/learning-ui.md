# 学习界面设计规格（M2 · UMG）

> 作者：DeepSeek Harness · 2026-10-21 · 任务书 [../tasks/deepseek-round4.md](../tasks/deepseek-round4.md)
> 实现：Codex（UMG/Blueprint）；数据：D8 `DT_Content_*` + D2 `DT_Vocabulary`；文案 key：D14 `ST_UI`。
> 目标：读写3 的学习界面，同时是**记忆的界面**——2090 年的老人回看 2026 年课堂，冷色、半透明、有年代噪点，不做得像普通学习软件。

## 1. 设计基调

**叙事前提**：玩家在 2090 年通过“记忆回放”看 2026 年的大学英语课。学习界面不是弹窗，而是**记忆匣里取出的胶片界面**：冷蓝底、玻璃/磨砂、扫描线、极轻的胶片颗粒；交互像在调取一段旧记录，而不是打卡刷题。

| 项 | 规格 |
|----|------|
| 主色 | 记忆蓝黑 `#0B1220`；面板玻璃 `#121A2B`（80% 不透明） |
| 辅色 | 冷青 `#7FD4E8`（可交互）；旧纸暖 `#D8C9A8`（正文/记忆强调）；暗金 `#B79A5E`（奖励/底片） |
| 强调 | 珊瑚红 `#E0736A`（错误/断片，克制使用，不超过画面 5%） |
| 文字 | 正文 `#E6ECF5`，次要 `#9FB0C7`，禁用 `#5D6B80` |
| 字体 | 中文：思源黑体 / Noto Sans SC；英文：Source Serif 4（课文） + Inter（UI）；数字等宽 |
| 质感 | 磨砂玻璃面板 + 2px 内高光；细扫描线（透明度 4%）；角落有“记忆编号/时间戳”小字（装饰） |
| 动效 | 出现 = 光粒凝结（0.25s）+ 轻微失焦→清晰；切换 = 扫描线擦除（0.18s）；**禁止**弹跳/弹性过冲（老年记忆应缓慢、克制） |
| 音乐/音效 | 沿用现有钢琴环境音；点击为轻胶片声，答对为极轻的风铃，答错为短促哑音 |

## 2. 信息架构

```
W_Root (CommonUI Root)
├─ W_SubtitleBar        底部字幕（电影模式常驻，学习时降到 1 行）
├─ W_NavRail / W_MobileNav   桌面左侧导航 / 手机底部导航
├─ W_UnitSelect         单元选择（6 单元）
├─ W_LearningHub        单元内：词汇 / 阅读 / 听力 / 翻译 / 写作 / 小测
├─ W_WordCard           词汇卡（翻转式主动检索）
├─ W_Reading            课文阅读 + 段落锚点
├─ W_Listening          听力播放 + 题目
├─ W_Translation        翻译练习
├─ W_Writing            写作提纲/生成
├─ W_Quiz               小测（混合题型）
├─ W_Review             间隔复习（SM-2 队列）
├─ W_Result             本轮结果 / 记忆底片
└─ W_Pause / W_Settings  暂停 / 设置（含字幕、字号、对比度）
```

## 3. 通用组件

| 组件 | 说明 |
|------|------|
| `W_GlassPanel` | 磨砂玻璃面板：圆角 12、描边 1px `#2A3A55`、扫描线叠加 |
| `W_MemoryChip` | 词汇 chip：单词 + 音标 + 掌握度（模糊/清晰/闪光） |
| `W_ProgressRail` | 顶部细进度条 + 记忆编号（`U03 / 05`） |
| `W_Button` | 主按钮（冷青描边，悬停发光）、次按钮（透明）、危险/断片（珊瑚） |
| `W_ChoiceList` | 选项列表：左侧 1/2/3/4 键位提示，选中后 0.4s 锁定 |
| `W_SubtitleBar` | 底部字幕：英文主行 + 中文次行，可切换仅中文/仅英文/关闭 |
| `W_FocusRing` | 手柄/键盘焦点环：2px `#7FD4E8`，不依赖颜色（外扩 3px 缺口） |

## 4. 界面详细规格

### 4.1 W_UnitSelect 单元选择

```
┌──────────────────────────────────────────────────────────┐
│  ◇ 记忆匣 / 读写3                         12:07 · 2090   │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │ 01 数字时代   │  │ 02 人生故事   │  │ 03 出发      │   │
│  │ 6/6 段 · 已归档│  │ 4/6 段        │  │ 锁定         │   │
│  │ ▓▓▓▓▓▓▓░░░   │  │ ▓▓▓▓▓░░░░░   │  │ ░░░░░░░░░░   │   │
│  └──────────────┘  └──────────────┘  └──────────────┘   │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │ 04 工作的快乐 │  │ 05 中国航天   │  │ 06 经济      │   │
│  └──────────────┘  └──────────────┘  └──────────────┘   │
│  选中单元 → 右侧浮出「进入记忆」；未解锁显示原因           │
└──────────────────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_Unit`（`UnitId/UnitNumber/Title/TitleZh/Theme/WordIds`）+ 进度存档（Codex 负责 `USaveGame`）。
- **状态机**：`Idle → Hover/Selected → Entering(0.3s 光粒) → LearningHub`；锁定单元点击 → 显示解锁条件（完成上一单元）。
- **适配**：桌面 3×2 卡片网格；手机 1 列纵向滑动，卡片高 88dp，顶部保留单元编号。
- **无障碍**：卡片标题 ≥20pt；进度用「6/6 段」文字 + 条形双编码；焦点顺序左→右、上→下。

### 4.2 W_LearningHub 单元内导航

```
┌──────────────────────────────────────────────┐
│  ◇ Unit 01 数字时代：我们准备好了吗？           │
│  [词汇] [阅读] [听力] [翻译] [写作] [小测]      │
│  ─────────────────────────────────────────    │
│  本单元 30 词 · 已掌握 12 · 待复习 5            │
│  ▸ 继续上次：阅读 B 段 · 第 3 幕                │
└──────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_Unit.WordIds`、`DT_Vocabulary`（按 `UnitId` 过滤）、`DT_Content_Section`。
- **状态机**：Tab 切换（无动画阻塞）→ 子界面；`继续上次` 依据存档。
- **适配**：桌面横向 Tab；手机横向滚动 Tab，字号 ≥15pt。

### 4.3 W_WordCard 词汇卡（主动检索优先）

```
┌──────────────────────────────────────────┐
│  03 / 30            digital      /ˈdɪdʒɪtl/ │
│                                          │
│   [ 点击翻面 ]   （先回忆释义）             │
│   ────────────────────────────────       │
│   adj. 数字的；数码的                      │
│   The club used a digital calendar...    │
│   [模糊] [清晰] [闪光]                     │
└──────────────────────────────────────────┘
```

- **数据绑定**：`DT_Vocabulary.Word/Phonetic/Pos/Meaning/Example/Example_zh/Collocation`；掌握度来自存档。
- **交互**：空格/点击翻面 → 自评（模糊=短间隔、清晰=中、闪光=长）；左右键上一词/下一词；`1` 播放发音（TTS/真人）。
- **状态机**：`Front → Back → Rated → Next`；翻面动画 0.2s（无弹跳）。
- **适配**：手机卡片占 70% 高度，底部三按钮大热区 ≥48dp。
- **无障碍**：音标提供屏幕阅读器文本；翻面后焦点移到释义；支持纯键盘。

### 4.4 W_Reading 阅读

```
┌────────────────────────────────────────────────┐
│  Section B · Living in the digital world        │
│  ┌ 段落 1 ▸ 锚点：数字港口 ─────────────────┐   │
│  │ For many students, the digital world ...│   │
│  └─────────────────────────────────────────┘   │
│  ┌ 段落 2 …                                   │  
│  点击段落 → 右侧「段落锚点」浮层（词 + 例句）    │
│  [朗读本段]  [隐藏释义]  [下一段]               │
└────────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_Section.Title/Passage`、`DT_Content_ReadingQuestion`（`Section=A` 时追加）、`DT_Vocabulary`（段落内高亮词）。
- **交互**：段落高亮；点击生词 → 词汇卡（不打断阅读）；`朗读` 调 TTS（课文用 TTS，见 D13）。
- **状态机**：`Reading → ParagraphFocus → WordPeek → Reading`；完成后解锁该段小测。
- **适配**：桌面双栏（正文 60% + 词汇侧栏 40%）；手机单栏，正文行宽 ≤ 38 中文字/65 英文字符，字号 17pt。
- **无障碍**：行距 1.6；段间距 ≥16dp；可开「大字模式」（正文 20pt）。

### 4.5 W_Listening 听力

```
┌────────────────────────────────────────────┐
│  Listening · The digital age                │
│  ▶  ━━━━━━━━━━━●──────────  00:42 / 02:10  │
│  [0.75×] [1.0×] [1.25×]   [显示原文]        │
│  ── 题目 1/4 ──                             │
│  What did the speaker's attention diary ...│
│  ( ) A ...   ( ) B ...   ( ) C ...   ( ) D │
└────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_ListeningQuestion.Question/Options/Answer/Explanation` + 听力原文 `DT_Content_*`（`listening` 数据行）；音频由 D13 VO manifest 生成。
- **交互**：播放/暂停/进度拖拽；**先听题后看原文**；显示原文即标记“已看原文”（影响掌握度）。
- **状态机**：`Idle → Playing → Answered → Next`；答错允许重听 1 次。
- **适配**：手机播放条置底，题干预留 3 行；选项按钮 ≥48dp。
- **无障碍**：提供英文字幕开关（默认关，符合听力训练）；波形/进度有文字时间。

### 4.6 W_Translation 翻译

```
┌──────────────────────────────────────────────┐
│  翻译 · 第 2 句 / 4                             │
│  中文：减少不必要的消息提醒有助于学生保护注意力。 │
│  ┌────────────────────────────────────────┐  │
│  │ 输入英文…                              │  │
│  └────────────────────────────────────────┘  │
│  关键词提示：notifications · protect · attention│
│  [提交]   [看参考]                              │
└──────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_Translation.Zh/EnReference/Keywords`。
- **交互**：先提交再看参考（生成效应）；提交后做关键词命中检查，给出「命中 2/3」反馈；参考译文可朗读。
- **状态机**：`Writing → Submitted → Compared → Next`；未提交前「看参考」按钮弱化并提示会失去自评。
- **适配**：手机输入框至少 4 行、弹起键盘时标题收起。
- **无障碍**：输入框 label 明确；错误提示用文字 + 图标，不只靠颜色。

### 4.7 W_Writing 写作

```
┌──────────────────────────────────────────────┐
│  写作 · Unit 01                               │
│  Prompt: Are we ready for the digital age?    │
│  ┌ 提纲 1  State your position ▸ [已填]      │
│  ┌ 提纲 2  Develop one example ▸ [写作中]     │
│  ┌ 提纲 3  Explain your reasoning ▸ [待填]    │
│  ┌ 提纲 4  Conclude ▸ [待填]                  │
│  词块：attention · notification · connection   │
└──────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_Writing.Prompt/Outline`、`DT_Content_OutlinePoint.Point`、`DT_Vocabulary`（按 `UnitId` 提供词块）。
- **交互**：按提纲逐点填写（每点 2–4 句）；词块点击插入；提交后给“结构 / 用词 / 语法”三行反馈（可先本地规则）。
- **状态机**：`Outline → Drafting → Review → Done`；中途退出保存草稿。
- **适配**：桌面左提纲右编辑器；手机纵向折叠提纲。
- **无障碍**：字数统计可朗读；自动保存提示用文字。

### 4.8 W_Quiz 小测（混合题型）

```
┌────────────────────────────────────────────┐
│  小测 · 7/10        ▓▓▓▓▓▓▓░░░   得分 60    │
│  ── 阅读理解 ──                             │
│  What problem led the club to run ...      │
│  1) ...   2) ...   3) ...   4) ...         │
│  [提交] [跳过]                              │
└────────────────────────────────────────────┘
```

- **数据绑定**：`DT_Content_MicroCheck`（`section_a/b/c`）、`DT_Content_ReadingQuestion`、`DT_Vocabulary`。
- **交互**：1–4 键作答；答后立即显示对错与解析；连对显示 streak。
- **状态机**：`Question → Answered → Next → Result`；超时/退出保存进度。
- **适配**：手机题干最多 4 行，选项单列。
- **无障碍**：解析文字可滚动并聚焦；分数有文字说明。

### 4.9 W_Review 间隔复习

```
┌──────────────────────────────────────────┐
│  复习 · 今日 12 词        [薄弱] [全部]    │
│  ── 词 1/12 ──                            │
│   notification    /ˌnoʊtɪfɪˈkeɪʃn/        │
│   [模糊] [清晰] [闪光]                     │
│  下次复习：1 天后 · 已复习 2 次             │
└──────────────────────────────────────────┘
```

- **数据绑定**：`DT_Vocabulary`（按复习队列 ID）+ 存档 SM-2 状态（`reps/interval/due`，沿用现有调度）。
- **交互**：翻面 → 自评三档 → 自动下一词；可切换「薄弱词」。
- **状态机**：`Queue → Card → Rated → Queue/Empty`；完成后显示「本轮复习完成」。
- **适配**：手机与桌面一致（单卡）；桌面支持键盘 1/2/3。
- **无障碍**：到期时间用文字；色盲安全（三档按钮形状/图标不同）。

## 5. 桌面 / 手机适配

| 断点 | 布局 | 字号 | 交互 |
|------|------|------|------|
| 桌面 ≥1280dp | 左侧导航 + 内容 900dp 居中；阅读双栏 | 正文 16–18pt，标题 24–32pt | 鼠标 + 键盘 1–4/空格/方向键 |
| 平板 768–1279dp | 单栏 + 顶部 Tab；阅读单栏 | 正文 16–18pt | 触摸 + 键盘 |
| 手机 <768dp | 底部 Tab + 全屏面板；卡片 88dp | 正文 ≥17pt，触控热区 ≥48dp | 手势滑动 + 底部大按钮 |

- 所有面板用 `SafeZone`（刘海/圆角）；横屏时字幕条不超过底部 25%。
- 字体缩放：设置里「标准/大/特大」三档（1.0/1.15/1.3×），UMG 用 `Scalable Text` + `Font Size` 变量。

## 6. 无障碍要求

- **字号**：桌面正文 ≥16pt、手机 ≥17pt；最小可点击文字 ≥14pt。支持系统级字体缩放。
- **对比度**：正文/背景 ≥4.5:1；大标题 ≥3:1；禁用态 ≥3:1（用透明度 + 虚线边框，不只靠颜色）。
- **色彩**：对错同时用图标（✓/✕）+ 文字；术语不高亮为唯一线索。
- **动效**：提供「减少动态」开关（关闭光粒、扫描线、镜头晃动）；闪烁不超过 3 次/秒。
- **键盘/手柄**：全部可聚焦；焦点环 2px 冷青 + 外扩缺口；Esc 暂停；Tab 顺序与视觉一致。
- **字幕**：英/中/双语/关四档；语速可调（0.75×–1.25×）；字幕可调背景不透明度。
- **屏幕阅读**：按钮有可读名称；进度用文字补充（「第 3 题，共 10 题」）。

## 7. 本地化 key 约定（D14）

- 统一前缀：`ui.<模块>.<元素>`，例：`ui.learn.wordcard.reveal`、`ui.reading.next_paragraph`、`ui.quiz.submit`、`ui.review.interval_days`。
- 所有用户可见文本禁止硬编码；`ST_UI` 由 `Tools/data_import_strings.py` 生成。
- 数字/日期用 `{0}` 占位；英文与中文 key 一一对应（见 D14 测试：key 唯一、无空翻译）。

## 9. UMG 实现注意（给 Codex）

1. 用 **CommonUI**：`UCommonUserWidget` + `CommonActivatableWidgetStack` 管理界面栈；返回键统一处理。
2. 文本用 `UTextBlock` + `ST_UI` StringTable key（`LOCTEXT` 或 StringTable 引用），不要在 Blueprint 里写死中文。
3. 列表用 `ListView`（虚拟化），避免 30 词/72 题的 Widget 全量创建。
4. 答题按钮用 `CommonButtonBase` 派生，保证键盘/手柄/触控同一套焦点。
5. 阅读/翻译的长文本用 `ScrollBox` + 自动换行；字号变化走 `SetFontSize` 的全局样式。
6. 所有动画用 UMG Animation（0.15–0.3s，无 overshoot）；提供 `bReduceMotion` 开关。
