# 角色交付 QA 清单（D4）

> 每个角色在 `Content/Characters/<id>` 交付前逐项打勾。判定以 UE Lookdev 关卡 + `Tools/qa/report.py` 为准。
> 负责人：Claude（三维）执行，DeepSeek 提供工具与阈值；Codex 提供对比相机/关卡。

## 0. 交付物门槛

- [ ] `Content/Characters/<id>` 存在：MetaHuman 资产、Groom（头发/眉毛/睫毛）、服装、材质齐全
- [ ] `Saved/Compare/<id>/{front,q34,side,back,closeup}.png` 五张渲染齐全（与参考图同机位/布光）
- [ ] `Docs/qa/<id>-report.md` 已生成，且**没有 FAIL**（N/A 项需 Claude 书面说明）
- [ ] `Docs/tasks/STATUS.md` 已登记交付

## 1. 穿模（clipping）

- [ ] 面部：说话/张嘴时下唇不穿下巴，舌/齿不露穿
- [ ] 肩颈：转头 90° 时颈部不穿高领/开衫
- [ ] 四肢：屈肘 120°、抬臂 90° 时袖子/腋下不穿
- [ ] 坐姿：大腿与椅面/裤裆不穿；衣摆不穿大腿
- [ ] 手部：握拳/张开、拿道具（保温杯、档案袋）时手指不穿

## 2. 发丝穿透

- [ ] Groom 发根不穿头皮；发丝不穿额头/耳朵
- [ ] 刘海发丝不穿眉毛/眼镜框
- [ ] 长发不穿肩、后背、衣领
- [ ] 低/高马尾发束不穿头骨
- [ ] 头发与服装之间无“发丝从布料里长出来”的穿模
- [ ] 远景发片 LOD 与近景 Groom 过渡处无跳变/裂缝

## 3. 眼睛

- [ ] 眼球与眼窝贴合，无眼白外露过多
- [ ] 至少一个真实高光（catchlight），位置符合布光
- [ ] 虹膜纹理清晰、瞳孔大小可调（明/暗环境）
- [ ] 眨眼极值：上眼睑完全遮住眼球，无穿插；左右对称
- [ ] 湿润感（泪膜高光）不过曝

## 4. 牙齿与口腔

- [ ] 张嘴（jawOpen）时牙齿无悬空、无穿唇
- [ ] 上下牙咬合关系正确（不反颌/不龇牙）
- [ ] 口腔内部黑暗处理正确，不露出空洞
- [ ] 舌头不穿牙齿/下唇

## 5. 表情极值

- [ ] ARKit 52 个表情全部可用；至少 `eyeBlinkLeft/Right`、`jawOpen`、`mouthSmileLeft/Right`、`browInnerUp` 正确
- [ ] 表情组合：微笑 + 眯眼 + 抬眉同时成立，不穿脸
- [ ] 极值不破面（无尖刺、无法线翻转）
- [ ] 表情过渡平滑（无抖动，Animation Blueprint 采样正常）

## 6. 布料自交

- [ ] Chaos Cloth 极端动作（跑、蹲、抬腿）下布料不自交、不穿身体
- [ ] 长裤/裙子与腿部碰撞体正确，无“塌陷”或“爆开”
- [ ] 开衫/衬衫下摆不穿裤腰；领口不穿脖子
- [ ] 静止 30 s 后布料无持续抖动/漂移

## 7. LOD 切换

- [ ] LOD0–LOD3（或项目定义的层数）齐全；远近切换无弹跳/变亮变暗
- [ ] 发丝 Groom LOD 与发片 LOD 在 15 m / 8 m 过渡自然（按相机距离）
- [ ] 材质/Material Instance 在 LOD 间一致（无贴图丢失）
- [ ] 阴影在不同 LOD 下连续（无突然消失）

## 8. 性能

- [ ] 1440p + Lumen 下，单个英雄 LOD0 ≤ **2.5 ms GPU**（`stat gpu` / `ProfileGPU` 截图存档）
- [ ] 远景自动切到发片 LOD，GPU 时间低于 LOD0 的 50%
- [ ] 单个角色 Draw Call ≤ 项目预算（记录实际值）
- [ ] 内存/贴图预算：baseColor ≤ 2048²（如项目允许 4K 需记录理由）

## 9. 和参考图并排

- [ ] 正面 / 3/4 / 侧面 / 背面 / 特写 五张并排图已生成（`report.py`）
- [ ] 关键点：正面平均误差 ≤3 px、3/4 ≤8 px
- [ ] 侧面脸部剪影 IoU ≥0.95
- [ ] 头发剪影 IoU ≥0.85
- [ ] 人工确认：骨相、五官、发型、肤色与参考图一致（不接受“风格相似”）
