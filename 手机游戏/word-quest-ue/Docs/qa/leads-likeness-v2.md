# 男女主相似度：现状评审与 v2 方案（Claude，2026-10-28）

## 现状（v1，2026-10-22/23 渲染）

对比图：`img/leads-v1-male-vs-ref.jpg`、`img/leads-v1-female-vs-ref.jpg`（上排参考，下排 UE 当前）。

结论：**不合格，差距是根本性的，不是微调能补的。**

| 项 | 参考图 | v1 现状 |
|----|--------|---------|
| 脸型 | 男：窄长 V 下颌、高鼻梁、深眼窝；女：小 V 脸、大眼、尖下巴 | 中脸塌陷、鼻头肿、颅顶过大，像被关键点拉扯过 |
| 皮肤 | 冷白、通透、几乎无瑕的 CG 皮肤 | 橙黄，带照片投影的光照残留和斑块 |
| 眼睛 | 大，双眼皮，深色虹膜；女有眼线和长睫毛 | 小，眼睑松弛 |
| 头发 | 男：黑色层次碎发，侧扫刘海；女：酒红长直发，空气刘海 | 光头（Groom 没绑定） |
| 服装 | 男：白衬衫敞领；女：浅蓝吊带和细项链 | 灰色背心占位 |
| 光照 | 白底柔光棚拍 | 灰底，侧光偏暗 |

根因：
1. 照片关键点 conform 把 MetaHuman 网格硬拉向 2D 关键点，三维结构被破坏。像素误差看着不大（3.9–7.7 px），但脸是歪的。**这说明像素指标骗人，必须以并排目视为准。**
2. 照片投影皮肤把参考图的光照和色调带进了反照率。
3. 头发、服装、眼睛这几项一直没有落地。

## v2 方案（Claude 亲自做）

1. **几何**：不再用关键点 conform。改为：
   - 先在 MHC 预设里挑最接近的年轻东亚男女模板做混合（blend）；
   - 再用参数化雕刻按参考调比例：脸宽、下颌 V 线、颧骨、鼻梁高度、眼睛大小和眼型、唇形、颈长；
   - 强制左右对称；
   - 关键点只用来**测量**比例，不再直接驱动顶点。
2. **皮肤**：MHC 程序化皮肤，选冷白肤色、低粗糙度和细毛孔，不投影照片。女主加淡腮红、唇色 MLRose 一类的自然玫瑰色，替换现在的正红。
3. **眼睛**：虹膜深棕，放大到 MHC 上限附近；女主加眼线、长睫毛和卧蚕高光。
4. **头发**：
   - 男主用 MH 短层次 Groom，黑色，侧扫刘海，鬓角收短；
   - 女主用 MH 长直 Groom 加刘海卡片，颜色 #5A1A22 酒红，发尾略内扣。
   - 都要做 strands 和 cards 两级 LOD。
5. **服装**：男主白色敞领衬衫，女主浅蓝吊带加细链项链。用 MH 服装库最接近的款式，改色改领型。
6. **对比渲染**：`ue_render_compare.py` 增加白底柔光棚 preset，和参考图同机位、同焦距并排出图。
7. **验收**：前 / 3/4 / 侧 / 特写四张并排，**目视**一眼认得出是同一个人才算过；关键点误差只作辅助。
