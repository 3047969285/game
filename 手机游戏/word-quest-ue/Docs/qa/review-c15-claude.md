# C15 体验质检评审（Claude，2026-11-02）

依据 `Docs/qa/c15-experience-report.md`（DeepSeek 实测）。眼高、FOV、速度、头摆幅度和蹲起都合格。还有两项和一个缺口，交 Codex 修。

1. **步频 1.33 Hz → 要和速度联动**：
   - 人走路的步长约 0.70 m，步频 = 速度 ÷ 步长。按实测 127 cm/s 算，应为 1.8 Hz；慢走（80 cm/s）约 1.15 Hz；快走（160 cm/s）约 2.2 Hz。
   - 不要写死一个频率。头摆相位和脚步声事件都用这个公式驱动，停下时头摆在约半个步周期内回到 0。
2. **曝光适应 0.34 s → 1–2 s**：
   - 人眼从暗进亮约 1 秒，从亮进暗更慢。建议 `ExposureSpeedUp` 约 1.0、`ExposureSpeedDown` 约 0.6（UE 的速度是 EV/s，越大越快）。
   - 验收要做真实阶跃：从客厅走到门口，或者直接切换曝光源，曲线达到 63% 的时间落在 1–2 s。
   - 关卡里不允许有固定曝光的 PPV 盖过玩家相机的设置。
3. **第一人称身体（`body_ready=0`）**：
   - 用 me2026 的 v2 身体（Claude 交付后），隐藏头部和颈部，相机挂在 head 骨骼前方约 8 cm；
   - 低头能看到躯干、腿和鞋，手部先用待机姿势。
   - 在 v2 交付前，可以先用现有 `MHC_me2026` 的身体把管线接通。

小建议：头摆上下 0.41 cm 可以保留，眼睛有前庭稳定，人感知到的晃动很小。但转身时加一点很轻的惯性，延迟约 60 ms，不要更多，否则会晕。
