# 第 1 单元场景画面评审（Claude，2026-10-23）

评审对象：`Docs/qa/scenes/u01*/`，共 33 张 4K 机位截图（Codex C7 / C10 输出）。
结论：**全部退回。** 先修第 1 条（渲染管线），修好后才能谈材质和细节。

## 1. 阻塞：28 / 33 张截图纯黑（平均亮度 0.0）

不是“偏暗”，是像素全部为 0，即截图根本没有渲染出画面。

- 全黑：u01a_s1 basket/chess、u01a_s2 faces、u01a_s3 under_table、u01a_s4–s8 全部、u01b_s2、s4–s8、u01c_s1 scan、u01c_s2、c4–c6。
- u01a_s3 wide、u01b_s1 city 几乎全黑（亮度 0.7 / 1.1）。
- u01b_s3 room 过曝（平均亮度 205）。
- 能看的只有 4 张：u01a_s1 wide、u01a_s2 wide、u01c_s1 stall、u01c_s3 street。

怀疑方向，请 Codex 逐项排查：

1. 每个 set 只激活当前 set 的 PPV / 曝光，可能导致其他机位曝光补偿或 bias 变成极端值。
2. SceneCapture 预热次数不够，TAA 历史为空。
3. 局部 RectLight 的半径隔离把机位所在的 set 排除在光照之外。
4. 机位落在几何体内部。

**修复验收**：33 张截图平均亮度都在 40–170 之间，且没有大面积纯黑。checker 要自动拦截全黑截图，判 FAIL，不能输出“完成”。

## 2. 能看到的 4 张：仍是白模水平

- **材质**：柱子是棋盘格占位贴图，墙、地、家具都是单一灰色，没有 PBR 细节，也没有磨损、污渍、贴花。
- **几何**：u01c_s4 table 是 BasicShapes 的圆柱和方块。
- **布景**：几乎没有小物件，桌面空荡；没有体积雾和光束。
- **人物**：仍是占位，没有出现。

对照 `quality-bar.md` 第 2–3 节，以上每一项都不达标。

## 3. 后续评审方式

每次重新出图后，Claude 逐张对照 quality-bar 评审，DeepSeek 的 `scene_audit.py` 先做机器筛查。全黑、过曝、纯色材质这几项机器能查的，必须先过机器筛查再交给 Claude。
