# 画质标准（一步到位）

用户要求：从一开始就达到《极限竞速：地平线 6》级别的画质和细节，不做粗糙版本，避免返工。本文是所有场景、物件、灯光的验收标准，Claude 和 Codex 共同遵守。不达标的东西不进最终关卡。

## 1. 资产来源（按优先级）

1. **Fab / Quixel Megascans**：照片扫描的 3D 资产、表面材质、贴花，UE 内免费。
   - 引擎已装 `Fab`、`Bridge`、`MegascansPlugin`；
   - 需要用户在 UE 里登录一次 Epic 账号。
2. **Poly Haven（CC0）**：HDRI 天空、材质、模型。下载前征得用户同意。
3. **代码建模**：只用于没有扫描资产可用的东西（二维码牌、记忆特效、特定电子设备、书本封面等）。必须达到第 2 节的标准。
   - `SourceArt/Props` 里现有的 94 个代码物件只作为**布景占位**（定比例、定位置）。
   - 最终关卡里，它们要被扫描资产替换，或者升级到第 2 节的标准。

## 2. 物件标准

- **几何**：开启 Nanite。
  - 主体物件 ≥ 20 万三角面，或直接用扫描资产。
  - 所有硬边都有真实倒角，看不到原始方盒子的边。
- **材质**：每个材质都要有完整 PBR 贴图（BaseColor / Normal / ORM）。
  - 近景 ≥ 2K，中景 1K；禁止纯色材质。
  - 必须有磨损：边缘磨亮、灰尘、指纹、划痕、色差。
  - 布料、木纹、皮革、金属、塑料各用对应的扫描表面。
- **贴花**：地面污渍、墙面污迹、桌面杯印、纸张折痕。每个布景至少 10 处。
- **小物件密度**：近景桌面、柜面不能是空的。按场景放杂物：笔、纸、充电线、杯子、钥匙、书、植物。

## 3. 灯光与渲染

- Lumen 全局光照与反射（关卡允许时打开硬件光追），虚拟阴影贴图，开启 MegaLights 评估。
- 天空：每个外景用 HDRI 或 Sky Atmosphere + 体积云；室内的窗外要有真实景物，不能是纯色。
- 体积雾：每个布景都有体积雾和光束（窗光、灯光）。
- 每个布景一个 Post Process Volume：
  - 手动曝光、电影色调映射；
  - 轻微胶片颗粒、暗角、色差；
  - 镜头景深（CineCamera 实际焦距 + 光圈）。
- 回忆风格叠加（溶解、光尘、冷色边缘光）放在上述写实画面之上，不能用来掩盖粗糙。

## 4. 人物

MetaHuman（主角已在制作），配合 Groom 头发和服装。不允许用胶囊占位进入最终版本。

## 5. 验收

- **截图**：每个布景按 JSON 里的机位出 4K 截图，放在 `Docs/qa/scenes/<sceneId>/`。
- **评审**：Claude 逐张对照第 2–3 节检查，不达标退回。
- **对照**：和 FH6 同类场景（室内 / 街景 / 黄昏）截图并排对比。
- **性能**：画质优先；移动端另做 LOD 和画质档位，不能反过来压低桌面画质。
