## 1. 颜色

| 项 | 值 |
|----|----|
| 底色 sRGB | `#15110f`（近黑，带一点冷褐） |
| 暗部 | `#0c0a09` |
| 高光/丝光 | `#2b2724`（冷灰高光，`#3a3531` 只用于发丝最亮线） |
| 说明 | 不是纯黑 `#000000`；强光下能看到偏冷的灰褐色反光，避免“假发感” |

## 2. 分区长度（cm）

| 区域 | 长度 | 说明 |
|------|------|------|
| 前额刘海（侧扫） | **12–15** | 从分缝扫向右侧（图像左→右），发尖到眉尾/眼尾，最长几缕到颧骨 |
| 头顶（层状碎发） | **8–10** | 3–4 层，层次差 2–3 cm；顶部有几缕 4–6 cm 的翘起碎发 |
| 两侧（耳上） | **4–5** | 贴头，耳朵**露出**；鬓角保留 1.5–2 cm |
| 耳后 | **6–7** | 向后上方梳，发尖略翘 |
| 颈后 | **5–6** | 向下收尖（V 形收口），后颈干净 |
| 总体视觉 | 短碎发，顶部蓬松、两侧收紧、颈后收尖 | 剪影“上宽下窄” |

## 3. 梳向与形态

- **分缝**：约 7:3，分缝线在**角色左前额**（图像左侧），不是硬直缝，发根有自然交叉。
- **前额**：从分缝向右侧横向扫过额头，发丝略盖住眉尾；右侧（图像右）发根立起、形成一个小峰。
- **头顶**：向后上方梳，形成**蓬起**；不贴头皮，有碎发翘起（7–9 缕）。
- **两侧**：向后贴头，耳上收紧；耳前有一小缕自然垂下的碎发。
- **耳后/颈后**：向后、向下收，发尖**尖锐**（碎发剪法，不是齐剪）。
- **蓬起高度**：头顶比头皮高 **5.5–6.5 cm**；后脑高 **3.5–4.5 cm**；两侧高 **1–1.5 cm**。
- **发量密度**：高（相对等级 **8.5/10**）；发丝偏粗硬，支撑蓬松感。
- **发尖形态**：**尖**（点剪/碎剪），不是齐平；鬓角尖、颈后尖。

## 4. 标准轮廓（Groom 验收）

1. 用 `Tools/qa/compare_silhouette.py <参考图> <渲染图> --region hair` 与上面的目标掩码对比。
2. 判定：**头发剪影 IoU ≥ 0.85**（方案 §4），正面和侧面都要过。
3. 允许差异：顶部碎发的随机翘起（3–5% 面积）；**不允许**发片边缘、块状发束、发尖齐平。

## 5. Groom 生成建议（给 Claude）

- 引导线：**250–400 根**，沿分缝向两侧分布；顶部节点加密。
- Clump：中等（0.35–0.5），顶部 clump 大、两侧小；Noise 0.15–0.25 制造碎发感。
- Frizz：低到中（0.1–0.2），只在发尖和顶部。
- 发丝宽度：根 0.9、尖 0.2（相对 groom_width）；总发丝数 6–8 万（LOD0）。
- 发根贴头皮，避免整片“头盔”；分缝处发根略立起。
