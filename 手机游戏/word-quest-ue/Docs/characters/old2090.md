# old2090 ·“我”（2090）

## 一句话人物
2090 年的雨夜，84 岁的他把意识送回 2026 年——一个在最好的时代里，仍旧想念那间漏风的教室、和那群后来散掉的人的老人。

| 项 | 值 |
|----|----|
| 年龄 | 84 岁（2026 年 20 岁 + 64 年） |
| 身高 | 1.78–1.80 m（青年 1.84 m，脊柱压缩约 4–6 cm） |
| 体型 | 偏瘦，肩窄，胸椎后凸 12–18°，腹部略前凸 |
| 身份 | me2026 的同一人；记忆旅程的“你” |
| 声音 | 低、慢、气息多；句尾常收轻 |

## 故事作用
2090 公寓雨夜开场的第一人称/第二人称载体；上浮定格时说话；所有回忆都是他“想起来”的版本。
叙事上他不评价、只记得，所以表演要克制。

## 外貌规格（MetaHuman 可建）
### 脸型 / 骨相（与 me2026 强制一致）
- 窄长脸，头型比例长（headAspect 同 me2026）；下颌窄、下巴略长；颧骨略高。
- 老年脂肪流失后：太阳穴凹、颧弓下缘凹陷、下颌角更清楚但皮肉松弛；颈阔肌下垂，下颌线断续。
- 与青年版共用同一眉骨起伏、同一鼻梁高度、同一鼻基底宽度（Claude 做老年化时只改皮肉与毛发，不许改骨相）。

### 五官
- 眼：狭长，上睑下垂使眼裂高度缩短约 20%；双眼皮松弛成多层褶；下眼睑袋明显，眼尾下垂。
- 眉：稀疏银白、眉尾下坠，眉峰变平。
- 鼻：鼻梁直（与 me2026 同高），鼻翼略塌，鼻尖微垂；鼻翼沟加深。
- 唇：唇红变淡、变薄，唇缘模糊；嘴角自然向下 2–3°。
- 耳：耳垂随年龄变长、变软，耳轮略薄。

### 皮肤与色斑
- Fitzpatrick III，冷调偏灰；面部底色 sRGB `#c9a58c`，颈部偏暗 `#b9977e`。
- 鼻翼与颧骨有淡红毛细血管扩张 `#b9796a`；眼周灰紫 `#8d7a78`。
- 皱纹：额横纹 3–4 条、川字纹、鱼尾纹、法令纹深、唇纹纵向；颈横纹。
- 老年斑：颧骨两侧 3–8 mm、颜色 `#8a5a3c`；手背与前臂更多（各 6–10 处）。
- 老年斑与痣位置必须在贴图里，不要只靠程序化噪声。

### 身高 / 体型
- 1.78–1.80 m；肩宽 43–45 cm；手背血管明显、指间关节变粗（右手第 2 指间关节最明显）。
- 站立时重心偏右；步幅 45–55 cm，步频慢。

### 剪影辨识度
银白后梳 + 金属圆框眼镜 + 宽大开衫 + 轻度驼背 = 灰蓝色调的“收拢”轮廓。与 me2026 靠**姿态与毛发**一眼分开，靠**骨相**确认是同一人。

## 发型规格
- 颜色：银白 `#cfd0d4`（略带冷蓝，不要纯白）。
- 长度：顶部 4–6 cm、两侧 3–4 cm、后颈 3 cm。
- 发际线：M 形后移，前额发际比青年后退 3–4 cm；鬓角稀疏向下延伸 2 cm。
- 发量：约为青年 35%；头顶可透见头皮。
- 走向：全部向后梳，耳后压平，后颈收短；不用发油，保持干燥蓬松感。

## 表情与姿态习惯（动画用）
- 眨眼频率低（8–10 次/分），眨眼偏慢；回忆触发时眼神失焦 0.5–1 s。
- 说话前有 0.8–1.2 s 停顿；句尾收气，肩膀轻微下沉。
- 右手拇指摩挲表带；独处时下巴微抬看窗外；坐下前先用手撑膝。
- 笑起来只动嘴角，眼睛先亮一下再收回；叹气时先深吸一口气。

## MetaHuman 参数建议
