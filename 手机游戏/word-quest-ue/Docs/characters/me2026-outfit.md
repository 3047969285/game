# me2026 服装规格（2026 中国大学生 · 白衬衫 + 黑西裤 + 黑皮鞋）

> 来源：`~/Downloads/male_sheet.png`（白底正/侧/背三视图，1536×1024）。身高按 **1.84 m** 换算。
> 测量：`Tools/qa/measure_sheet.py` + 人工核对（脚本切三视图、白底前景分割、横截线宽度、颜色中位数）。
> 量测参数：前视图 bbox 高 **963 px** → **5.234 px/cm**；腰头位置 68.0 cm（距头顶）→ 距地 **1.16 m**。

## 1. 衬衫（白，卷袖，塞入裤腰）

| 部位 | 规格 | 依据 |
|------|------|------|
| 领型 | 标准尖领（point collar），领角自然外翻 | 三视图 |
| 领高 | 3.4 cm（领座 1.2 cm + 领面 2.2 cm） | 图测 ×5.234 px/cm |
| 领尖长 | 6.5 cm | 图测 |
| 门襟 | 明门襟，宽 3.2 cm；扣子 **6 粒**可见（领下 1 粒被领口遮住，实际 7 粒） | 前视 |
| 扣子 | 直径 1.1 cm，四眼，白色贝壳扣 | 图测 |
| 下摆 | **塞进西裤**，腰头外露；两侧无开衩 | 前/侧视 |
| 袖长 | 长袖，**卷到前臂中上段**：卷边下缘在肘下 **8–10 cm**（约距头顶 73.9 cm 处见前臂皮肤） | 前视皮肤出现位置 |
| 卷边宽度 | 双层卷，宽 **5.0 cm**（每层约 2.5 cm） | 图测 |
| 版型 | 合体微松，肩线平，胸围约 100 cm，衣长（后中）约 78 cm | 肩宽 47.2 cm（横截线）推算 |

**材质判断**：纯棉或棉混纺府绸，表面哑光、有细密斜纹；领子挺括，卷袖处有自然折痕；略微洗旧。
**颜色 sRGB**：`#eceef2`（亮部偏冷白，阴影 `#c9ccd4`；不要用纯白 `#ffffff`）。
**磨损/穿法**：领口第一颗扣**解开**（露出锁骨），袖口卷得随意、左右不完全对称；下摆塞得略松，腰侧有 1–2 道堆褶。

## 2. 西裤（黑，高腰直筒微锥）

| 部位 | 规格 | 依据 |
|------|------|------|
| 腰头 | 高腰，腰头高 **4.5 cm**；腰线距地 **1.16 m**（距头顶 68.0 cm） | 前视暗色起始 |
| 裤型 | 直筒微锥（锥度约 4%），有前褶（单褶） | 前/侧视 |
| 裤长（外长） | 约 **1.04 m**（腰头到裤脚） | 腰线 1.16 m - 裤脚离地 0.12 m |
| 裤脚口 | 宽 **21–22 cm**（单腿），脚口离地 **11 cm**，鞋面上有 **2–3 cm** 堆褶 | 横截线 0.94h 处 fg 宽 22.9 cm 减去鞋 |
| 口袋 | 侧缝直插袋 + 后双嵌线袋 | 背视 |
| 门襟 | 拉链 + 暗扣 | 前视 |

**材质判断**：羊毛/羊毛混纺精纺西裤，表面有细微哑光与垂坠感；前褶压线清晰。
**颜色 sRGB**：`#19181b`（中位采样 `25,24,27`；高光 `#2e2d33`，褶皱阴影 `#0e0e10`）。
**磨损/穿法**：膝部轻微起拱、裤脚有轻微磨毛；不是新熨的西裤，允许 2–3 道自然褶。

## 3. 皮鞋（黑，系带，圆方头）

| 部位 | 规格 | 依据 |
|------|------|------|
| 款式 | 系带德比/牛津（无布洛克），**圆方头**（偏圆，非尖头） | 前/侧视 |
| 鞋底 | 厚 **2.8 cm**（含橡胶大底），跟高 **2.5 cm** | 侧视鞋底轮廓 |
| 鞋口 | 低帮，露出脚踝；鞋舌短 | 侧视 |
| 鞋长 | 约 **30 cm**（42 码） | 图测 |
| 鞋面 | 光面牛皮，鞋头有浅折痕 | 图测 |

**材质判断**：光面牛皮（calf），擦亮但鞋头有 2–3 道横向折痕；鞋底为橡胶。
**颜色 sRGB**：鞋面 `#141416`（近黑，高光 `#3a3a40`）；鞋底 `#1b1b1e`。

## 4. 配件与整体

| 件 | 规格 | 颜色 |
|----|------|------|
| 腰带 | 黑色细皮带（宽 3 cm），银色方扣 | 皮带 `#1a1a1c`、扣 `#9a9ca2` |
| 袜子 | 黑色中筒袜，坐下时露边 | `#1d1d20` |
| 手表（可选） | 简约钢带或黑皮带表 | 表盘 `#d8d8d0` |
| 发型 | 见 [me2026-hair.md](me2026-hair.md) | — |

**整体轮廓**：瘦高（1.84 m）、肩线平、长腿；白衬衫 + 黑裤 + 黑鞋形成上下高对比；卷袖露出前臂是识别点。
**2026 年中国大学生依据**：白衬衫/黑西裤/黑皮鞋是答辩、面试、社团正式场合的常见搭配；不做奢侈品牌 logo，鞋子穿旧。
