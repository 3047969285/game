# rui · 同学 Rui

## 一句话人物
校史档案馆里最安静的那个，习惯把每一页纸的边角对齐——他相信证据，也相信人会被证据改变。

## 故事作用
Unit 2「两种人生」里第一个提出“去查档案”的人；他提供被忽略的证据，也负责在冲突里把话题拉回事实。

## 外貌规格（MetaHuman 可建）
### 脸型 / 骨相
- 长窄脸（jawWidth -0.45、jawLength +0.65、headAspect -0.65）：下巴长而窄、下颌线清楚但薄。
- 颧骨平（-0.1）、面颊瘦（cheekFull -0.3）；额头高（foreheadHeight +0.55），发际线略高。
- 侧面：鼻梁高长、下巴略后收，整张脸“竖长”。

### 五官
- 眼：小眼（eyeSize -0.25）、眼型偏细长；眼距宽（+0.35）；内双。
- 眉：眉位高（browHeight +0.25）、眉形平直、眉色深棕 `#4a3527`，厚度 0.45。
- 鼻：鼻梁高（noseBridge +0.45）、鼻子长（noseLength +0.55）、鼻翼窄；鼻尖略尖。
- 嘴：嘴窄（mouthWidth -0.25）、唇薄（-0.3）；说话时下唇轻微内收。

### 皮肤与标记
- Fitzpatrick II–III，冷白 `#dcc0a8`；脖子略黄。
- 颧骨处少量雀斑（0.3 强度，颜色 `#c49a78`）；鼻梁两侧有眼镜压痕（浅红）。
- 眼下轻黑眼圈（常熬夜整理档案）。

### 身高 / 体型
- 1.87 m；瘦（BMI 约 19）；肩窄、腰细、腿长。
- 走路低头看路、步子不快；站着时重心单腿，另一只脚尖点地。

### 剪影辨识度
**全场最高 + 长脸高额 + 棕色微卷 + 方框眼镜 + 蓝格纹**；与 an 的宽方剪影形成最明显的对比。

## 发型规格
- 颜色：深棕 `#8a6a48`（阳光下偏栗，阴影里偏灰）。
- 长度：8–12 cm；侧分（3:7，分缝在左）；额前有 2–3 缕微卷碎发。
- 卷度：2A–2B 微卷，发尾自然弯；发量中等偏多、发质偏软。
- 鬓角到耳中；后脑发尾略翘；不用发胶，自然蓬松。
- 眼镜：方框（深棕 `#3a2a1e` 或黑 `#1f1f23`），镜片有指纹与一点反光；镜腿略夹太阳穴。

## 表情与姿态习惯（动画用）
- 推眼镜：用食指+中指侧面推鼻梁（每 1–2 分钟）。
- 说话前清嗓子；不确定时用“我查过……”开头。
- 翻档案前用指腹把页角压平；对不齐的纸会重新叠。
- 冲突时身体会后仰，双手交叉放在桌面；真正生气时反而更小声。
- 站着时重心在左腿，右脚尖点地。

## MetaHuman 参数建议
- 脸长、下颌窄、额高；鼻梁高长、鼻翼窄；眼小、眼距宽、眉高平。
- 肤色冷白，加少量雀斑；眼镜压痕做在贴图里。
- 微卷发 Groom（棕色）；方框眼镜作为静态网格挂件。
- 体态偏直、肩窄，避免肌肉感。

## 一致性 / 备注
- 他的“安静”不是害羞，是在观察；表演不要低头缩肩太多。
- 蓝格纹是他的记忆点，颜色必须固定（不要在不同单元换色）。
