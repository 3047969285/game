# lin 服装规格（2026 中国大学生 · 浅蓝 A 字连衣裙 + 银色高跟鞋 + 项链）

> 来源：`~/Downloads/female_sheet.png`（白底正/侧/背三视图，1536×1024）。身高按 **1.68 m** 换算。
> 测量：`Tools/qa/measure_sheet.py` + 人工核对。量测参数：前视图 bbox 高 **994 px** → **5.917 px/cm**；
> 腰线（连衣裙收腰缝）距头顶 32.3% → **54.2 cm**（距地 **1.14 m**）；裙摆距地 **28.6 cm**（膝下约 18–19 cm）。

## 1. 连衣裙（浅蓝，无袖细吊带，A 字长裙）

| 部位 | 规格 | 依据 |
|------|------|------|
| 领口 | **方形/一字领**，前领口宽约 24 cm、深约 8 cm（露出锁骨） | 前视 |
| 吊带 | **细吊带**，宽 **1.0–1.2 cm**，肩带位置靠外（肩峰内侧约 4 cm） | 前/侧视 |
| 袖型 | 无袖（armhole 包边，宽 0.5 cm） | 三视图 |
| 胸衣 | 合体胸衣，公主线/胸省，贴合胸廓；背面有隐形拉链 | 正/背视 |
| 腰线 | **自然腰位**，收腰缝距地 **1.14 m**；腰围约 **64 cm**（前视腰宽 13.7 cm 为半宽投影） | 横截线 0.323h |
| 裙型 | **A 字长裙**，从腰线向外展开；腰到裙摆约 **75 cm** | 腰 1.14 m → 摆 0.29 m |
| 裙长 | 至**小腿中段**：裙摆距地 **28.6 cm**，即**膝下约 18–19 cm** | 横截线 |
| 下摆宽度 | 前视投影宽 **57.3 cm**；估算下摆周长 **2.0–2.4 m**（含褶量） | 横截线 0.80h |
| 褶/裁片 | 软褶 + 裁片：**6–8 片**（正面可见 4 条垂坠褶线，背面对称） | 三视图 |

**材质判断**：雪纺/乔其纱（chiffon/georgette），哑光、轻盈、微透（裙摆边缘有轻微透光）；内衬同色薄衬。
**颜色 sRGB**：`#d1dae9`（中位采样 `209,218,233`；阴影 `#b9c6da`，高光 `#e8eef7`）。
**磨损/穿法**：裙摆有自然垂褶、无破损；吊带长度调得略松，领口微微前倾；腰线平整无水洗痕。

## 2. 高跟鞋（银色，尖头细跟）

| 部位 | 规格 | 依据 |
|------|------|------|
| 款式 | 尖头包头细跟（stiletto pump），浅口 | 前/侧视 |
| 跟高 | **7.0 cm**（±0.5；细跟直径约 0.8 cm） | 侧视鞋跟比例估算 |
| 鞋头 | 尖头，鞋头微翘 | 侧视 |
| 鞋面 | 金属银皮革/漆皮，鞋口浅（露出脚背） | 图测 |
| 底厚 | 前掌底 **0.5 cm** | 图测 |

**材质判断**：金属银皮革（metallic leather）或漆皮，表面高光强、反射环境；鞋跟为同色金属包跟。
**颜色 sRGB**：`#c9ccd4`（高光 `#eef0f4`，暗部 `#9aa0ab`）。
**磨损/穿法**：鞋面干净、鞋跟有轻微磨损；站姿重心略偏后。
