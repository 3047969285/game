## 1. 颜色

| 项 | 值 |
|----|----|
| 底色 sRGB | `#482123`（酒红，偏冷；采样中位 `72,33,35`） |
| 暗部 | `#2e1416` |
| 高光 | `#8a3a42`（暖红丝光，`#a34a52` 仅用于最亮发丝线） |
| 说明 | 不是亮红/紫红；室内偏深棕红，光下才透红。不要做成 `#800000` 纯酒红 |

## 2. 分区长度（cm）

| 区域 | 长度 | 说明 |
|------|------|------|
| 前额齐刘海 | **8–9** | 齐眉（眉骨上方 0.5–1 cm），**齐剪**、发尖略圆；中间略长、两侧略短（自然弧度） |
| 头顶 | **10–12** | 贴头，无蓬起（+2.5–3 cm）；发旋处有分缝感 |
| 两侧（耳前） | **30–35** | 垂到胸上沿；贴脸颊，遮住部分下颌线 |
| 耳后 | **55–60** | 垂到背部中段；耳朵半露 |
| 颈后/后脑 | **95–105** | 垂到髋部/大腿上段；发尾齐、微圆 |
| 总体视觉 | 长直发，前额齐刘海，发尾厚重 | 剪影“上窄下宽、垂坠” |

## 3. 梳向与形态

- **分缝**：中分（被齐刘海遮住，不明显）；发旋在头顶偏后 2 cm。
- **前额**：从发旋向前、垂直下落，齐刘海覆盖额头到眉；刘海发丝**直**、微向内扣。
- **两侧**：从耳前垂直垂到胸前，贴脸颊；耳后发丝被耳朵压住、自然外露。
- **后侧**：垂直下落，发丝顺滑、无层次（只在发尾 5 cm 做轻微层次）。
- **发尖**：**齐/微圆**（blunt cut，不是尖锐碎发）；发尾厚重。
- **蓬起高度**：头顶仅 +2.5–3 cm（贴头）；两侧贴颊，不蓬。
- **发量密度**：中高（相对等级 **7.5/10**）；发丝细软、光泽强（丝滑直发）。

## 4. 标准轮廓（Groom 验收）

1. `compare_silhouette.py <参考图> <渲染图> --region hair` 与目标掩码对比（女主发色深红，用 `--hair-vmax 150`）。
2. 判定：**头发剪影 IoU ≥ 0.85**，正面/侧面都要过。
3. 允许差异：发尾 3–5 cm 的随机分叉；**不允许**发片边缘、块状发束、发尾齐成一条硬线。

## 5. Groom 生成建议（给 Claude）

- 引导线：**300–500 根**，从发旋向四周放射，前额引导线垂直向下。
- Clump：大（0.5–0.65），长直发要成束但不结块；Noise 低（0.05–0.1）。
- Frizz：很低（0.03–0.08），保持丝滑。
- 发丝宽度：根 0.8、尖 0.15；总发丝数 8–10 万（LOD0）。
- 刘海与两侧发丝要**分离成独立 clump**，避免整块头套；发根贴头皮，发尾有重量感。
