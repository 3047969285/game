# 第一单元家庭客厅生活细节

## 产品需求说明书

仅处理 `u01a_s1`，保留家庭共同阅读、棋局、入口手机篮三处叙事焦点。后侧窗边和书架旁各布置一个真实圆边桌：书册、茶碟茶杯、便笺与铅笔；窗侧用完整花盆/土/植物组合，墙面用两个家庭相框和时钟。中央一米通道、正面棋盘和右前手机篮周围不新增遮挡。所有新物件使用本地已交付 Poly Haven CC0 网格，保留原始材质，禁止方盒代替缺失成品。

当前是布置器交付，不宣称已完成截图验收。书籍进口轴向、相框贴墙朝向、铅笔默认轴向需在 UE 实景检查。缺少窗帘、家庭照片插图、书架内部层板精确支撑位置、完整阅读灯具；由独立 missing 列表返回，不能当作最终画质通过。

## 接口文档

`derive_room_dressing(scene, mapping_doc) -> {items, missing}`：确定性纯函数，无文件读写，不改源数据；只对 `u01a_s1` 生效。位置为局部米，source 为 `polyhaven_cc0`。`support` 必须指向前序物件，子物件 Z 为相对支撑面距离。

`spawn_room_dressing(u, spawn, scene, mapping_doc) -> {spawned, missing}`：传入 Unreal 模块及现有 `spawn(cls,label,world_cm,tags)`。加载真实资产，多部件盆植共享组合包围盒和同一个变换。用包围盒真实底部与水平中心修正不居中 pivot；茶杯落在碟实际顶部、铅笔落在便笺顶部、书册逐本叠在前一本实测顶部。新增演员带 scene/layer/clutter/source/dressing 标签。加载失败或支撑缺失跳过并记录，不生成替代几何体，不修改共享网格或材质。

集成在 builder 原有通用 clutter 后，主控宜对本场景禁用原通用桌面 clutter，避免同位置重复摆放。此接口不负责保存关卡；调用方负责串行锁、保存与截图。

## 测试

`python3 -m unittest discover -s Tools -p test_living_room_dressing.py`

验证确定性和不改源数据、本地所有引用 .uasset 存在、支撑依赖顺序、中央接近通道和手机篮留白、非目标场景无改动、缺失映射不创建桌面悬浮物、旋转后非中心 pivot 底部修正。UE 实景验证由主控持锁执行：逐机位检查穿插/默认资产朝向、相框与墙面、书摞厚度与边桌承载范围；不以纯函数测试替代最终视觉验收。


### 本轮补充：朝向、座位与书架

需求：保留 reading_lamp；相框转向室内；为坐着下棋的 Jason、Jack 补齐真实木椅，已有阅读扶手椅不重复。角色位置属于故事焦点，棋椅可进入焦点区域，仍需实机检查坐姿与座面贴合。

接口：新增 `existing_bookshelf` 支撑名，运行时只接受当前 set 唯一 `kit:bookshelf` actor，读取世界包围盒真实顶部，为六本书提供承托。书架缺失/重名时明确返回 support unavailable。书架内部层板尚未精确测量，不用估算坐标塞满并冒充验收通过。相框 yaw=180 是待实机核验的纠偏方向，不宣称已视觉通过。

测试：新增帧朝向、两张棋椅、避免重复阅读椅、reading_lamp 保留和实测书架支撑契约；本地最终网格存在与顺序测试继续覆盖。未启动 UE。
