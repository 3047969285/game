# 统计存档可靠性

## 产品需求说明书

依据 README 的 JSON 持久化与退出时保存设计，保存新统计失败时，已成功保存的历史记录与个人最佳必须保持可读取。序列化不能直接截断正式文件；成功保存仍保留最近 500 条记录。

同时验证 Windows 应用入口可编译：程序集明确声明 Windows 支持范围，与现有 user32、字体 API 和 win-x64 发布目标一致；初始化时明确检查窗口对象，消除空引用与平台误报，不调整原有发布目录。

## 接口文档

无 HTTP 接口。`IStatsRepository`、JSON 字段、文件名不变。两个保存方法先序列化到同目录唯一临时文件，关闭文件后再替换正式文件；失败或取消时传播原异常并清理临时文件，保留旧文件。两份统计文件分别替换，不提供跨文件事务；不承诺突然断电时的磁盘持久化。

## 测试

运行 `dotnet test AimForge.Tests/AimForge.Tests.csproj -c Release`。回归验证正常保存、非法浮点数引发序列化失败后旧文件保持不变、临时文件清理、并发保存与 500 条保留上限。Windows 图形程序的帧率与输入延迟需在目标机器实测。

2026-10-19 验证：使用 .NET SDK 9.0.319，Release 测试 12 项通过。修复前两个失败保存测试会把原文件变为空文件，修复后原文件字节完全不变；并发、保留上限与取消测试通过。临时文件无法清理时记录警告，不掩盖原始保存异常。未验证 Windows 图形程序运行和 700+ FPS 性能目标。

Windows 应用源码也已在 macOS 交叉编译验证：输出位于临时目录，构建 0 警告、0 错误；仓库内预编译的 Windows 程序未替换，发布时仍须在 Windows 目标环境验证。
